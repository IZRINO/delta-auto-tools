# 三角洲行动工具

Windows 桌面工具，给《三角洲行动》玩家用。把两件反复手工做的事收进一个本地应用：

1. **特勤处挂机** — 多账号轮流收取制作台、兑换子弹、检查限时商品、买交易行。
2. **局内辅助** — 摩斯解码并自动输入、倒计时、计数、按住连发、屏幕识别触发、息屏、攻略站。

纯本地，没有账号体系，也没有服务端。不保存、不输入 QQ 密码。

[下载安装包](https://github.com/IZRINO/delta-auto-tools/releases/latest) · [特勤处教程](docs/特勤处使用教程.md) · [许可证](LICENSE)

## 能做什么

**特勤处**

- 多 QQ 账号按顺序值班：登录、进游戏、收制作、兑子弹、查限时、买交易行。
- 启动后默认暂停。点「继续」并通过检查后，到期任务马上跑，未来任务到点再跑。
- 失败会标到具体制作台或具体子弹，不会整号一起停。
- 可选联网利润筛选：达标的子弹立刻兑换，不达标当天轮空。

**局内**

- 摩斯：框选报码区域，识别后自动输入。
- 计时器 / 计数器 / 连发器：游戏画面上的透明读数，点击穿透，不抢鼠标。
- 识别触发：快捷键、参考图、识色，命中后播音频、按键或点击。
- 息屏：只挡画面，识别截图和键鼠照常。
- 攻略网站：主窗口里打开，不用另开浏览器。

配置可以做成多套快照，切换、复制、导入导出。全局总开关一关，热键和自动化全部停。

## 用法

只支持 Windows。安装包从 [GitHub Releases](https://github.com/IZRINO/delta-auto-tools/releases/latest) 下载，管理员运行，启动时会有一次 UAC。

### 局内工具

打开对应页面，配好热键和区域即可。透明窗口跟游戏叠在一起，不会挡住准星、也不会抢走点击。全局总开关关掉后，这些热键全部失效。

### 特勤处

工具不替你登 WeGame。每个要跑的 QQ 必须先在 WeGame 里登录，并勾选「记住密码」。

建议按这个顺序：

1. 选好 WeGame 和游戏的 exe。
2. 填默认制作台时长、子弹目标和需要的点击点。
3. 添加账号（纯数字 QQ）。
4. 校准点击区域、识别区域和参考图，对关键模板点「测试」直到通过。
5. 分别做一次登录、导航、制作、子弹试运行。
6. 按每个账号当前真实状态做一次人工校正。
7. 点「继续」，把到期任务交给自动调度。

运行时会占用键鼠。遮挡游戏或 WeGame 的窗口先关掉。紧急停止热键只在特勤处操作期间有效。

完整步骤、校准项和失败处理见 [特勤处使用教程](docs/特勤处使用教程.md)。

## 开发

需要 Windows、[Bun](https://bun.sh/)、[Rust](https://rustup.rs/) stable，以及 [Tauri 2 前置条件](https://v2.tauri.app/start/prerequisites/)（WebView2、MSVC）。

```bash
bun install
bun run tauri dev    # 完整桌面开发，必须用管理员 PowerShell
bun run dev          # 只开浏览器 UI，热键和截屏不可用
bun run check        # 前端测试 + Rust fmt / clippy / test
```

模块约定、发布流程和架构说明在 [`AGENTS.md`](AGENTS.md)、[`CLAUDE.md`](CLAUDE.md) 和 [`droid-wiki/`](droid-wiki/overview/index.md)。
