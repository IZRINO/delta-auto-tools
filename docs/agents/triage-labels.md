# Triage Labels

技能使用五级标准分流角色。本文件将这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| 技能内置角色            | 仓库实际标签            | 含义                |
|-------------------|-------------------|-------------------|
| `needs-triage`    | `needs-triage`    | 维护者需要评估此 Issue    |
| `needs-info`      | `needs-info`      | 等待报告者补充信息         |
| `ready-for-agent` | `ready-for-agent` | 已充分定义，AFK 代理可直接接手 |
| `ready-for-human` | `ready-for-human` | 需要人工实现            |
| `wontfix`         | `wontfix`         | 不会处理              |

当技能提到某个角色（例如 "apply the AFK-ready triage label"）时，使用本表对应的标签字符串。

如需调整，请编辑右侧列以匹配实际使用的词汇。
