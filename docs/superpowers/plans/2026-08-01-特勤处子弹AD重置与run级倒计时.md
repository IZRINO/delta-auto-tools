# 特勤处子弹 A/D 重置与 run 级倒计时 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. 用户要求 Inline Execution，禁止子代理和 worktree。

**Goal:** 将子弹定位改为每目标 A/D 重置后绝对下滚，并让每个特勤处 run 首次键鼠提示为 5 秒、后续为 1 秒，同时为 `ammo.success` 建立同环境测试和超时截图证据。

**Architecture:** `LoginRuntime` 持有 run 级倒计时一次性状态，登录、制作、子弹 driver 通过同一 `run_id` 原子领取 5 或 1 秒。输入层提供可取消 A/D 序列，子弹 driver 复用现有滚轮与点击。校准 command 仅对游戏内模板恢复游戏并停放鼠标；`ammo.success` 单目标 timeout 在配置目录保存区域截图。

**Tech Stack:** Rust、Tauri 2、Tokio、Enigo、image、React 19、TypeScript、Vitest、Bun。

**提交约束:** 保持工作区未暂存、未提交；跳过所有 commit 步骤。

`try_start_kind` 初始化为 `false`。`LoginRuntime` 增加：

```rust
pub(crate) fn next_input_countdown_seconds(
    &self,
    run_id: u64,
    show_subsequent_countdown: bool,
) -> Result<Option<u8>, String> {
    let mut inner = self.inner.lock().map_err(|_| "登录试运行状态已损坏".to_string())?;
    let active = inner.active.as_mut()
        .filter(|run| run.snapshot.run_id == run_id)
        .ok_or_else(|| "特勤处 run 已结束，不能开始倒计时".to_string())?;
    if !active.first_input_countdown_claimed {
        active.first_input_countdown_claimed = true;
        Ok(Some(5))
    } else if show_subsequent_countdown {
        Ok(Some(1))
    } else {
        Ok(None)
    }
}
```

三个现有 countdown 实现传入 `true`，导航与制作固定探测输入传入 `false`，统一按领取结果循环，不新建计时器：

```rust
let Some(total) = self.runtime.next_input_countdown_seconds(self.run_id, true)? else {
    return Ok(());
};
for seconds in (1..=total).rev() {
    ensure_not_cancelled(cancelled)?;
    if let Some(snapshot) = self.runtime.update(
        self.run_id,
        LoginRunStatus::Countdown,
        None,
        format!("{seconds} 秒后执行键鼠操作"),
        Some(seconds),
    )? {
        emit_run_changed(&self.app, &snapshot);
    }
    wait_cancellable(Duration::from_secs(1), cancelled).await?;
}
```

登录 driver 必须先执行现有 `countdown_required` 判断，再领取时长。`ProductionGameNavigationDriver::click/press` 与 `ProductionCraftTrialDriver` 的固定探测点击必须请求 `false`，确保单独导航或单独制作试运行首个固定输入仍显示 5 秒，但同 run 后续固定输入不显示提示。

```rust
fn press_primary_key_sequence_with_emitter<E: InputEmitter>(
    emitter: &E,
    keys: &[PrimaryKey],
    delay_after_each_ms: u64,
    cancelled: &AtomicBool,
    generation: u64,
) -> Result<(), String> {
    for primary in keys {
        press_key_with_emitter(emitter, primary_to_key(*primary)?, cancelled, generation)?;
        wait_cancellable_input_delay(cancelled, generation, delay_after_each_ms)?;
    }
    Ok(())
}
```
