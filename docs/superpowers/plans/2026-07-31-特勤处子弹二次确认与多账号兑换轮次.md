# 特勤处子弹二次确认与多账号兑换轮次 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. 本计划固定 Inline Execution，不使用子代理。Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 增加 `ammo.confirm` 置顶二次确认步骤，并让现有多账号 round 在同一账号会话内合并执行到期制作与当天子弹任务。

**Architecture:** `build_schedule` 继续作为到期任务权威来源，`round_planner` 只冻结其输出；`game_navigation` 增加大厅与四制作台两个终点；`round_account` 组合登录、导航、制作、子弹；`ammo_runtime` 负责二次确认状态机并返回可分类结果。成功结果逐项持久化，账号级失败交给现有 `round_runner` 隔离后继续。

**Tech Stack:** Rust、Tauri 2、Tokio、React 19、TypeScript、Vitest、Bun。

**Execution constraint:** 当前分支按用户要求不 `git add`、不 commit。每个任务以定向测试和 `git diff --check` 作为 checkpoint。

fn confirmation_uncertain(error: AmmoDriverError, step: &str) -> TargetAttempt {
    match error {
        AmmoDriverError::Cancelled => TargetAttempt::Stopped(AmmoRunStop::EmergencyStopped),
        AmmoDriverError::Target(message) | AmmoDriverError::System { message, .. } => {
            TargetAttempt::Uncertain {
                step: step.to_string(),
                message,
            }
        }
    }
}

}

    .wait_and_click("ammo.confirm", Arc::clone(&cancelled))
    .await

    Ok(target) if target == "ammo.success" => TargetAttempt::Succeeded,

    &self,
    task: &round_planner::AccountRoundTask,
    cancelled: Arc<std::sync::atomic::AtomicBool>,

    let frozen = self
        .frozen(task)?
        .ammo
        .as_ref()
        .ok_or_else(|| round_runner::AccountRunError::account(
            "ammo.preflight",
            "子弹冻结配置缺失",
        ))?;
    let driver = ProductionAmmoDriver {
        app: self.app.clone(),
        settings: Arc::clone(&self.settings),
        coordinator: Arc::clone(&self.coordinator),
        runtime: Arc::clone(&self.runtime),
        run_id: self.run_id,
        account_id: task.account_id.clone(),
        day: frozen.day.clone(),
        game_executable_path: frozen.game_executable_path.clone(),
        mouse_parking_region: frozen.mouse_parking_region.clone(),
        targets: frozen.targets.clone(),

        frozen.entry_delays,
