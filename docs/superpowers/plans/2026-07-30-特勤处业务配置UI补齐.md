# 特勤处业务配置 UI 补齐 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在默认配置补齐子弹目标编辑器，在账号独立设置补齐四制作台“制作物品选择点击点”校准入口，并确保账号级点击点进入现有制作 runtime。

**Architecture:** 继续使用现有 `BusinessConfig.recipePoints` 与 `BusinessConfig.ammoTargets`。现有校准 overlay 和三个 calibration command 增加可选账号上下文；无账号上下文时保持全局校准行为，有账号上下文时只原子更新该账号 `independentBusinessConfig.recipePoints`。默认与独立配置共用一个前端子弹编辑器，不新增依赖或平行 schema。

**Tech Stack:** Rust、Tauri 2、React 19、TypeScript、Vitest、daisyUI、Bun。

---

## 文件结构

- `src-tauri/src/special_ops/mod.rs`：解析账号级配方点击点上下文，扩展校准 begin/submit/cancel，保留现有 active-run/revision/原子持久化边界。
- `src/components/app/special-ops-calibration-overlay.tsx`：透传可选 `account_id`。
- `src/components/app/special-ops-page.tsx`：复用子弹编辑器；默认配置显示子弹目标；独立配置显示四台账号级点击点入口。
- `src/components/app/special-ops-page.test.tsx`：UI source contract 回归。
- `droid-wiki/features/special-ops.md`：同步默认子弹和账号级点击点行为。
