# 制作试运行取消与收尾 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让制作开始确认提示准确，并使阻塞中的模板采样能在普通取消后及时退出和清理 operation window。

**Architecture:** 在 `template_observer` 内集中增加可取消的单次采样边界，三个采样流程只调用该边界，不改 matcher。制作流程通过 `CraftTrialDriver` 新增阶段通知，在生产点击完成后、`craft.abort` 识别前发布 Waiting 状态。普通取消仍由既有 worker 收尾，不提前释放 active run。

**Tech Stack:** Rust、Tokio、Tauri 2、内联 Rust 单元测试、Bun 质量门禁

- [ ] **Step 3: 实现统一可取消采样边界**

```rust
async fn sample_cancellable<S: SimilaritySampler>(
    sampler: &S,
    target: &RuntimeTemplate,
    cancelled: &AtomicBool,
) -> Result<f32, String> {
    ensure_not_cancelled(cancelled)?;
    tokio::select! {
        biased;
        _ = wait_until_cancelled(cancelled) => Err("模板识别已取消".to_string()),
        result = sampler.sample(target) => result,
    }
}

async fn wait_until_cancelled(cancelled: &AtomicBool) {
    while !cancelled.load(Ordering::SeqCst) {
        tokio::time::sleep(CANCELLATION_POLL_INTERVAL).await;
    }
}
```

将三个采样流程内所有直接 `sampler.sample(target).await?` 改为：

```rust
sample_cancellable(sampler, target, &cancelled).await?
```

async fn 生产点击后先提示确认制作再等待中止按钮() {
