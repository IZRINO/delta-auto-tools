# 特勤处业务配置与 24 小时任务时间轴 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 同一轮补齐制作备注、子弹点击/滚轮配置，并增加后端权威投影驱动的滚动未来 24 小时时间轴。

**Architecture:** 延续 `BusinessConfig` 作为默认与账号独立业务配置真相；Rust `build_schedule` 负责生成平铺、排序后的 24 小时任务，React 只负责锚点式 10 分钟视觉分组和小时网格。复用现有 calibration overlay，通过显式 scope 原子写入默认/账号业务点击点，不新增 command 或持久化文件。

**Tech Stack:** Rust、serde、Tauri 2、React 19、TypeScript、Vitest、daisyUI、Bun。

```typescript
export function groupTimelineTasks(tasks: TimelineTask[], windowMs = 600_000): TimelineTaskGroup[] {
    const sorted = [...tasks].sort(compareTimelineTasks);
    const groups: TimelineTaskGroup[] = [];
    for (const task of sorted) {
        const current = groups.at(-1);
        if (current && task.scheduledAtMs - current.anchorAtMs < windowMs) {
            current.tasks.push(task);
        } else {
            groups.push({anchorAtMs: task.scheduledAtMs, tasks: [task]});
        }
    }
    return groups;
}
```
