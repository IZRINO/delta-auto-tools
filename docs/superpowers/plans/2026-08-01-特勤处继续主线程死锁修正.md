# 特勤处“继续”主线程死锁修正实施计划

> **供 agentic worker 使用：** 必须使用 `superpowers:executing-plans` 按任务执行；本任务采用 Inline Execution，不使用子代理。

**目标：** 保留“点击继续后立即调度到期任务”规则，同时消除 scheduler 启动时与 Tauri 主事件循环形成的窗口 API 死锁。

**架构：** `special_ops_set_paused` 继续负责持久化暂停状态并 arm/disarm scheduler，但改为 async Tauri command，使 command 不占用主事件循环。scheduler、round、窗口隐藏函数与前端调用保持原接口；测试用独立 Rust contract test 锁定 command 的 async 执行边界。

**技术栈：** Rust、Tauri 2、Cargo test、Clippy、CodeGraph。
