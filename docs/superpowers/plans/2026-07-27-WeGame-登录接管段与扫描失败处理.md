# WeGame 登录接管段与扫描失败处理 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 每个账号登录只提示一次 3 秒键鼠接管，并在账号扫描失败时立即标记账号而不重启 WeGame。

**Architecture:** `ProductionLoginDriver` 保存本次登录接管段状态；首个登录 UI 点击完成后进入接管段，`wegame.gameEntry` 识别成功后退出。账号选择状态机只执行一轮，`NotFound` 或复制校验错误直接返回 `NeedsManualLogin`。

**Tech Stack:** Rust、Tokio、Tauri、现有 `LoginDriver` 与 `LoginRuntime`。
