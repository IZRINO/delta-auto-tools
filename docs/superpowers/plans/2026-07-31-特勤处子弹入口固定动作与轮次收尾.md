# 特勤处子弹入口固定动作与轮次收尾 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Inline execution only; do not dispatch subagents.

**Goal:** 将军需处、战术部门和赛季入口改为固定点击动作，保证子弹配置按普通/赛季稳定分组，并在多账号 round 正常完成或账号后暂停时关闭游戏。

**Architecture:** 保留 `ammo_runtime` 纯状态机与 `ProductionAmmoDriver` 边界，新增两项持久化等待并删除无效列表模板；前端用纯函数维护目标分组。round 通过既有 `RoundDriver` 增加收尾能力，生产实现复用 canonical 完整路径进程终止，不影响紧急停止和系统故障现场。

**Tech Stack:** Rust、Tokio、Tauri 2、React 19、TypeScript、Vitest、Bun、CodeGraph。

- [ ] **Step 3：实现最小稳定分组函数**

在 `special-ops-utils.ts` 导出：

```typescript
export function renumberAmmoTargets(targets: AmmoBusinessTarget[]): AmmoBusinessTarget[] {
    return targets.map((target, order) => ({...target, order}));
}

export function changeAmmoTargetSeasonal(
    targets: AmmoBusinessTarget[],
    id: string,
    seasonal: boolean,
): AmmoBusinessTarget[] {
    const target = targets.find((item) => item.id === id);
    if (!target || target.seasonal === seasonal) return targets;
    const remaining = targets.filter((item) => item.id !== id);
    const insertion = seasonal
        ? remaining.length
        : remaining.findIndex((item) => item.seasonal);
    const index = insertion < 0 ? remaining.length : insertion;
    remaining.splice(index, 0, {...target, seasonal});
    return renumberAmmoTargets(remaining);
}
```

`moveAmmoTargetWithinGroup` 只交换相邻同组目标；新增普通目标时插入第一个赛季目标之前。

- [ ] **Step 3：实现最小 round 收尾策略**

`RoundDriver` 增加：

```rust
async fn close_game(&self) -> Result<(), String>;
```

仅在两个位置调用：

- `PauseRequested` 返回前：关闭失败改为 `SystemFailure { step: "round.closeGame", ... }`，不重复保存暂停。
- 所有账号处理结束、返回 `Completed` 前：关闭失败先 `persist_paused("关闭游戏失败")`，再返回 `SystemFailure`；持久化失败拼接到 message。

`SystemFailure` 和 `EmergencyStopped` 原返回路径不调用 `close_game`。

- [ ] **Step 4：接 canonical 游戏路径生产实现**

`FrozenRoundRun` 增加一次 canonical 化后的 `game_executable_path: PathBuf`，传给 `ProductionRoundDriver`。生产 `close_game`：

```rust
async fn close_game(&self) -> Result<(), String> {
    use desktop_runtime::DesktopRuntime;
    let executable = self.game_executable_path.clone();
    tokio::task::spawn_blocking(move || {
        desktop_runtime::WindowsDesktopRuntime
            .terminate_exact(&executable, std::time::Duration::from_secs(10))
    })
    .await
    .map_err(|error| format!("关闭游戏任务失败: {error}"))?
}
```

只按完整路径关闭游戏，不关闭 WeGame。关闭发生在 `run_round` 返回前，因此 `run_round_worker` 后续持久化、operation window cleanup、scheduler wake 顺序保持不变。
