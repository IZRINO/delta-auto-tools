# 特勤处登录初始倒计时顺序 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 用户已指定 Inline Execution；不创建子代理、不暂存、不提交。

**Goal:** 登录试运行和多账号轮换均先完成 5 秒键鼠接管倒计时，再关闭旧游戏与 WeGame。

**Architecture:** 在共享 `LoginDriver` 加入单一初始倒计时接口，并由 `run_login_flow()` 在任何进程操作前调用。生产 driver 复用既有 5 秒 run 级倒计时状态；FakeDriver 只记录动作，从而用顺序断言覆盖安全边界。

**Tech Stack:** Rust、Tokio、Tauri、现有 `LoginRuntime`。

- [x] **Step 3: 最小实现初始倒计时**

在 `LoginStep` 首项加入 `InitialCountdown`；在 `LoginDriver` 声明：

```rust
async fn initial_countdown(&self, cancelled: Arc<AtomicBool>) -> Result<(), String>;
```

在 `run_login_flow()` 的进程结束循环前插入：

```rust
if let Err(result) = run_step(
    driver,
    LoginStep::InitialCountdown,
    &config.account_id,
    &cancelled,
    &mut on_step,
    driver.initial_countdown(cancelled.clone()),
)
.await
{
    return result;
}
```

`ProductionLoginDriver` 实现直接调用现有 `self.countdown(&cancelled)`；不得新增第二套倒计时、配置或延时。`FakeDriver` 记录 `Action::InitialCountdown` 后返回 `Ok(())`。

在 `login_step_message()` 为 `InitialCountdown` 增加“即将开始轮换操作”，使 operation window 在 5 秒期间显示语义正确的步骤。
