# 多账号制作台更改 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 默认账号配置增加「多账号制作台更改」：打开后按账号顺序登录到制作台停手，按下一账号热键切号；与轮换/试运行互斥。

**Architecture:** 纯逻辑放 `station_walkthrough.rs`（启用门禁、启用账号、下一号动作、游标）。运行复用 `start_account_session` 的登录+导航，成功即结束本次 run、游戏留下。热键由开关持有，不跟单次 run 清理绑死。不碰 `round_runner` 分桶。

**Tech Stack:** Tauri 2 + Rust + React 19 + Vitest

**Spec:** `docs/superpowers/specs/2026-09-01-多账号制作台更改-design.md`

## Global Constraints

- 开关关着：零运行影响。打开期间禁止继续轮换、禁止任何试运行。
- `stationWalkthroughEnabled` 只走独立 command，`save_settings` 强制沿用进程内值。
- 下一账号热键与紧急停止互斥。
- 紧急停止关掉本功能；无人值守登录按现有留现场；制作台等人无 run 时只关功能。
- 新 command 只进 `generate_handler![]`，不建 ACL。
- UI 文案中文；复用现有 Switch / Button / SoftAlert。
