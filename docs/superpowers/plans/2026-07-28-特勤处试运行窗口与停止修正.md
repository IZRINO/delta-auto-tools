# 特勤处试运行窗口与停止修正 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修正主窗口被隐藏/置顶、非登录试运行文案错误、失败后 run 残留及倒计时停在 1 秒的问题。

**Architecture:** 保留单实例 `LoginRuntime`，为 snapshot 增加最小 `runKind`。窗口仲裁统一过滤 `main` 与 `special-ops-operation`；所有 worker 结果无条件进入资源清理，业务错误与清理错误合并返回。制作动作在倒计时后发布 focus、guard、input 阶段。

**Tech Stack:** Rust、Tauri 2、React 19、TypeScript、Vitest、Cargo test
