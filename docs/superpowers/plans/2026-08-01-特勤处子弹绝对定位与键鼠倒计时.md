# 特勤处子弹绝对定位与键鼠倒计时 Implementation Plan

> **后续规则覆盖：** `docs/superpowers/plans/2026-08-01-特勤处子弹滚轮节流.md` 已将 `scrollSteps = 0` 改为不滚动直接点击，并为非零滚动增加逐次节流与点击前等待。本文件保留初始实现记录，不再作为当前滚轮语义来源。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将子弹目标定位改为“每个目标先向上滚 50 次置顶，再按顶部绝对步数向下滚动并点击”，并为每个连续键鼠操作块增加一次 3/2/1 提示。

**Architecture:** `ammo_runtime` 负责业务顺序和连续输入块边界，`ProductionAmmoDriver` 负责 operation window 倒计时及真实输入。持久化继续保留 `scrollDirection` 兼容旧 JSON，但 normalize 固定归一化为 `down`，runtime 不再消费方向。前端仅编辑“从列表顶部向下滚动次数”。

**Tech Stack:** Rust、Tokio、Tauri 2、React 19、TypeScript、Vitest、Bun

**执行约束:** Inline Execution；不创建 worktree，不使用子代理，不暂存、不提交；保持当前开发版运行。

- [ ] **Step 4: 实现可取消 3/2/1 倒计时**

在 `ProductionAmmoDriver` 增加私有方法，复用现有 `LoginRunStatus::Countdown`、`countdown_seconds` 与 `emit_run`：

```rust
async fn countdown(
    &self,
    cancelled: &Arc<std::sync::atomic::AtomicBool>,
) -> Result<(), ammo_runtime::AmmoDriverError> {
    for seconds in [3, 2, 1] {
        if cancelled.load(std::sync::atomic::Ordering::SeqCst) {
            return Err(ammo_runtime::AmmoDriverError::Cancelled);
        }
        if let Some(snapshot) = self
            .runtime
            .update(
                self.run_id,
                LoginRunStatus::Countdown,
                None,
                format!("{seconds} 秒后执行键鼠操作"),
                Some(seconds),
            )
            .map_err(|error| Self::system_error("ammo.countdown", error))?
        {
            emit_run(&self.app, &snapshot);
        }
        <Self as ammo_runtime::AmmoDriver>::delay(
            self,
            std::time::Duration::from_secs(1),
            Arc::clone(cancelled),
        )
        .await?;
    }
    Ok(())
}
```

倒计时只由以下输入块调用一次：

- `wait_and_click`：识别成功后、真实点击前。
- `click_unverified`：真实点击前。
- `position_and_click`：上滚前；覆盖“上 50 → 下 N → 点击”。

- [ ] **Step 5: 实现绝对定位输入块**

`position_and_click` 执行：

```rust
self.countdown(&cancelled).await?;
self.focus().await.map_err(|error| Self::system_error("ammo.window", error))?;
self.emit_update(LoginRunStatus::Inputting, "正在从列表顶部定位子弹")
    .map_err(|error| Self::system_error("ammo.targetPosition", error))?;
crate::input_simulation::scroll_region_down_cancellable(
    point.clone(),
    -50,
    Arc::clone(&cancelled),
)
.await
.map_err(|error| Self::cancelled_or_system(&cancelled, "ammo.targetPosition", error))?;
let steps = i32::try_from(scroll_steps)
    .map_err(|_| Self::system_error("ammo.targetPosition", "滚轮次数超出范围"))?;
if steps > 0 {
    crate::input_simulation::scroll_region_down_cancellable(
        point.clone(),
        steps,
        Arc::clone(&cancelled),
    )
    .await
    .map_err(|error| Self::cancelled_or_system(&cancelled, "ammo.targetPosition", error))?;
}
crate::input_simulation::click_region_center_cancellable(
    point.clone(),
    Arc::clone(&cancelled),
)
.await
.map_err(|error| Self::cancelled_or_system(&cancelled, "ammo.targetPosition", error))?;
self.park_mouse(cancelled)
    .await
    .map_err(|error| Self::system_error("ammo.targetPosition", error))
```

`scrollSteps = 0` 只跳过向下滚动，不能跳过向上 50 次。
