# 特勤处默认业务配置与人工校正 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 增加独立默认业务配置、账号级独立覆盖与四制作台原子人工校正，使 `Uncertain` 账号可安全恢复为 `Ready` 并进入现有批处理。

**Architecture:** Rust 领域层拆分业务配置与账号运行态，单一 resolver 生成执行器使用的有效配置。旧混合 schema 在 `normalize_settings` 中幂等迁移；人工校正通过独立 Tauri command 在 `SettingsCoordinator` revision 临界区内一次持久化四台。前端只编辑原始默认/独立配置，不自行合并执行值。

**Tech Stack:** Rust、serde、Tauri 2、React 19、TypeScript、Vitest、daisyUI、Bun。

- [ ] **Step 3: 写最小 schema 与 resolver**

```rust
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "camelCase")]
pub struct StationBusinessConfig {
    pub kind: StationKind,
    pub enabled: bool,
    pub duration_minutes: u32,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "camelCase")]
pub struct AmmoBusinessTarget {
    pub id: String,
    pub name: String,
    pub enabled: bool,
    pub seasonal: bool,
    pub scroll_steps: u32,
    pub order: u32,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "camelCase")]
pub struct AccountBusinessConfig {
    pub stations: Vec<StationBusinessConfig>,
    pub recipe_points: Vec<AccountRecipePoint>,
    pub ammo_targets: Vec<AmmoBusinessTarget>,
}

pub fn resolve_account_business_config<'a>(
    settings: &'a SpecialOpsSettings,
    account: &'a AccountPlan,
) -> Result<&'a AccountBusinessConfig, String> {
    if account.independent_settings_enabled {
        account.independent_business_config.as_ref()
            .ok_or_else(|| format!("账号 {} 已开启独立设置，但独立配置缺失", account.qq_account))
    } else {
        Ok(&settings.default_business_config)
    }
}
```

`SpecialOpsSettings.defaultBusinessConfig` 使用 `Option` 仅承接旧 JSON 缺字段，normalize 后保证 `Some`；写回 bootstrap 前转为必有值。四台运行态继续留在 `AccountPlan.stations`，子弹当天状态继续按稳定 target ID 留在账号。
