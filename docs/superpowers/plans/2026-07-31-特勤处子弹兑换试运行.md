# 特勤处子弹兑换试运行 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修正连续账号导航点击竞态条件，并交付能真实处理所选账号全部启用普通/赛季子弹目标的单账号兑换试运行与隔离恢复。

**Architecture:** `game_navigation.rs` 只增加现有导航状态机的首段固定等待。新建纯编排模块 `ammo_runtime.rs`，通过 driver trait 隔离点击/识别与持久化；`special_ops/mod.rs` 负责冻结配置、生产 driver、Tauri command、durable 写入和资源清理。前端复用现有账号选择、operation window、校准表格和人工校正 dialog。

**Tech Stack:** Rust、Tokio、Tauri 2、Serde、React 19、TypeScript、Vitest、Bun。

**执行约束:** Inline Execution；不用子代理，不建 worktree，不 stage，不 commit；所有编辑使用 `apply_patch`。

---
