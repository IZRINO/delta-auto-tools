# 制作台初始状态分流 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 制作试运行可从可收取或空闲状态继续；两者均未命中时安全结束。

**Architecture:** 模板观察器增加一次性多目标双采样。制作 driver 将结果映射为 `ClaimReady`、`Idle` 或 `None`；状态机按结果跳过或执行收取阶段。制作台点击守卫允许对应感叹号与空闲中文字。

**Tech Stack:** Rust、Tauri 2、Cargo test
