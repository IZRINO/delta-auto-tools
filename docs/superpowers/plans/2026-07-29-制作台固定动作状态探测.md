# 制作台固定动作状态探测 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用固定点击/等待序列和 `craft.abort` 一次性双采样替代奖励页、制作中与制作列表就绪识别。

**Architecture:** `SpecialOpsSettings` 保存三段全局等待；`CraftRunConfig` 冻结等待和仍在使用的校准目标。`run_craft_station` 先执行无通用倒计时的固定探测段，再按 `craft.abort` 双采样进入“Esc 返回”或“选择物品并生产”分支。旧共享制作中字段和废弃 targets 在加载规范化时自然清理。

**Tech Stack:** Rust、Tokio、Tauri 2、React 19、TypeScript、Vitest、Bun

- [ ] **Step 4: 实现固定探测状态机**

`run_craft_station` 接收 `CraftProbeDelays`，入口改为：

```rust
driver.click_unverified(&station_key, false, Arc::clone(&cancelled)).await?;
driver.fixed_delay(delays.space_ms, Arc::clone(&cancelled)).await?;
driver.press_space_without_countdown(Arc::clone(&cancelled)).await?;
driver.fixed_delay(delays.reopen_ms, Arc::clone(&cancelled)).await?;
driver.click_unverified(&station_key, false, Arc::clone(&cancelled)).await?;
driver.fixed_delay(delays.confirm_pinned_ms, Arc::clone(&cancelled)).await?;
driver.click_unverified("craft.confirmPinned", false, Arc::clone(&cancelled)).await?;

match driver.inspect_abort_once(Arc::clone(&cancelled)).await? {
    SingleConsistency::Matched { .. } => {
        driver.press_escape_without_countdown(Arc::clone(&cancelled)).await?;
        driver.wait_ready("game.stationGrid", cancelled).await?;
        return Ok(CraftStationOutcome::StillInProgress);
    }
    SingleConsistency::NotMatched { .. } => {
        driver.click_unverified(&recipe_key, true, Arc::clone(&cancelled)).await?;
    }
}
```

所有固定探测输入后的错误使用 `failure_after_input`；首次点击前的 stage 更新失败仍用 `failure`。保留按钮、补齐、购买、生产和最终 `wait_abort` 流程。
