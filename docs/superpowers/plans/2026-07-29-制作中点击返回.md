# 制作中点击返回 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `craft.abort` 命中后点击用户校准的返回点，替代无法被游戏稳定接收的 Esc 输入。

**Architecture:** 复用现有 `click_unverified` 输入路径，不新增 driver 方法。默认校准、业务 preflight 与单台试运行冻结配置统一加入 `craft.returnToStationGrid`；命中分支点击后继续用 `game.stationGrid` 双采样确认返回。

**Tech Stack:** Rust、Tauri 2、Tokio、Vitest 文档断言、CodeGraph。

**执行约束:** 当前会话使用 Inline Execution，不使用子代理或 worktree。生产代码在实机验收前不 stage、不 commit；文档计划可单独提交。

```rust
    driver
        .click_unverified(
            "craft.returnToStationGrid",
            false,
            Arc::clone(&cancelled),
        )
        .await
        .map_err(|message| failure_after_input("craft.returnToStationGrid", &message))?;

        .wait_ready("game.stationGrid", cancelled)

        .map_err(|message| failure_after_input("game.stationGrid", &message))?;

}
```
