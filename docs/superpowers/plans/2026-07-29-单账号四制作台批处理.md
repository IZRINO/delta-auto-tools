# 单账号四制作台批处理 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增当前账号四制作台批处理试运行，按固定顺序处理启动时已到期的制作台，并在每台后持久化与返回四制作台页面。

**Architecture:** 新建 `craft_batch.rs` 保存到期选择和可测试的顺序编排；现有 `craft_runtime.rs` 继续负责单台键鼠状态机，并提供页面确认/返回 helper 与单台输入追踪。`special_ops/mod.rs` 冻结所有批次配置、实现生产 driver、逐台权威持久化并复用现有 runtime 停止仲裁。

**Tech Stack:** Rust、Tokio、Tauri 2、React 19、TypeScript、Vitest、daisyUI、CodeGraph。

**执行约束:** 使用 Inline Execution，不使用子代理或 worktree。编码前启用 ponytail。严格 TDD；生产代码在实机确认前不 stage、不 commit。

```rust
use super::{AccountPlan, AccountStatus, StationKind, StationStatus};

#[derive(Debug, Clone, PartialEq, Eq)]
pub(crate) struct CraftBatchTask {
    pub station: StationKind,
    pub duration_minutes: u32,
}

pub(crate) fn select_due_craft_tasks(
    account: &AccountPlan,
    frozen_now_ms: i64,
) -> Result<Vec<CraftBatchTask>, String> {
    if account.status != AccountStatus::Ready {
        return Err("当前账号状态不是 Ready，禁止启动制作批处理".to_string());
    }
    let mut tasks = Vec::new();
    for kind in StationKind::all() {
        let Some(station) = account.stations.iter().find(|item| item.kind == kind) else {
            continue;
        };
        if !station.enabled || station.status == StationStatus::Uncertain {
            continue;
        }
        if station.finishes_at_ms.is_some_and(|value| value <= frozen_now_ms) {
            tasks.push(CraftBatchTask {
                station: kind,
                duration_minutes: station.duration_minutes,
            });
        }
    }
    Ok(tasks)
}
```

```rust
struct FrozenCraftBatchTask {
    task: craft_batch::CraftBatchTask,
    config: craft_runtime::CraftRunConfig,
}

fn freeze_craft_batch_run_configs(
    settings: &SpecialOpsSettings,
    account_id: &str,
    frozen_now_ms: i64,
) -> Result<Vec<FrozenCraftBatchTask>, String> {
    let account = settings.accounts.iter()
        .find(|account| account.id == account_id)
        .ok_or_else(|| "制作批处理账号不存在".to_string())?;
    let tasks = craft_batch::select_due_craft_tasks(account, frozen_now_ms)?;
    if tasks.is_empty() {
        return Err("当前账号没有到期制作台".to_string());
    }
    tasks.into_iter().map(|task| {
        let (config, _) = freeze_craft_run_config(settings, account_id, task.station.clone())?;
        Ok(FrozenCraftBatchTask { task, config })
    }).collect()
}
```

在 `craft_batch.rs` 定义：

```rust
pub(crate) struct StationAttempt {
    pub result: Result<CraftStationOutcome, CraftTrialFailure>,
    pub entered_input: bool,
}

pub(crate) struct CraftBatchSuccess {
    pub processed: usize,
}

pub(crate) struct CraftBatchFailure {
    pub station: StationKind,
    pub failure: CraftTrialFailure,
    pub entered_input: bool,
}

#[allow(async_fn_in_trait)]
pub(crate) trait CraftBatchDriver: Send + Sync {
    async fn ensure_station_grid(&self, task: &CraftBatchTask, cancelled: Arc<AtomicBool>)
        -> Result<(), CraftTrialFailure>;
    fn update_progress(&self, index: usize, total: usize, station: &StationKind)
        -> Result<(), String>;
    async fn run_station(&self, task: &CraftBatchTask, cancelled: Arc<AtomicBool>)
        -> StationAttempt;
    fn persist_started(&self, task: &CraftBatchTask, started_at_ms: i64)
        -> Result<(), String>;
    async fn return_started(&self, task: &CraftBatchTask, cancelled: Arc<AtomicBool>)
        -> Result<(), CraftTrialFailure>;
}
```

`run_craft_batch` 先对首台执行 `ensure_station_grid`，再逐台更新进度并运行。每次循环在首次输入前检查 `cancelled`；取消时以当前 task 返回 `entered_input=false`。`Started` 必须先 `persist_started`，再 `return_started`。station failure 保留原 `requires_uncertain`；persist failure 使用步骤 `craft.persistStarted`、`requires_uncertain=true`、`entered_input=true`；return failure 使用 helper 的步骤、`requires_uncertain=true`、`entered_input=true`。任何错误立即返回，禁止调用后续 task。

- [ ] **Step 3: 实现 ProductionCraftBatchDriver**

在 `mod.rs` 保存冻结 tasks，通过 station 查找 config。实现 `CraftBatchDriver`：

- `ensure_station_grid`：构造 `ProductionCraftTrialDriver` 并调用 `craft_runtime::ensure_station_grid`。

- [ ] **Step 4: 实现 run_craft_batch_worker**

worker 调用 `craft_batch::run_craft_batch`。无 stop reason 时：成功 → `Succeeded`；批次失败按 `failure.requires_uncertain` 调用 `persist_craft_failure_uncertain_with`，否则只返回失败。存在 stop reason 时，传入 `failure.station` 与 `failure.entered_input` 调用现有 `persist_craft_stop_with`，从而保证普通取消在当前台输入前不标记、输入后标记；Emergency 继续 fail-closed。
