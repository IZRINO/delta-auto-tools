# 特勤处联网利润筛选 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. 本项目固定 Inline Execution；禁止子代理、worktree、stage、commit。

**Goal:** 在现有特勤处多账号 scheduler 与子弹 round 前增加可关闭的联网利润 gate：KKRB 主源、Moligod 隐藏 WebView 备用、截止时间后自动绕过，同时保持现有制作、登录、兑换、暂停和失败语义。

**Architecture:** 持久化层只保存利润规则、目标引用和查询审计；当前会话资格、generation、查询节奏和 active round 目标只存在内存。单一 scheduler 从“只启动 round”改成调度 QueryProfit / LaunchRound 两种动作；round 冻结目标 ID 与利润决策快照，执行期不再读取新配置。Moligod 通过无 IPC 权限的隐藏 Remote WebView 读取 DOM，不使用截图、OCR、键鼠或网页排序。

**Tech Stack:** Rust 2021、Tauri 2.11、Tokio、reqwest 0.13、React 19、TypeScript 6、Vitest 4、linkedom、daisyUI 5、Bun。

在 SettingsCoordinator 增加：

~~~rust
pub fn with_expected_revision_change<T, E>(
    &self,
    expected_revision: u64,
    operation: impl FnOnce() -> Result<T, E>,
) -> Result<(T, u64), E>
where
    E: From<String>,
{
    let mut revision = self
        .revision
        .lock()
        .map_err(|_| E::from("配置写入协调器已损坏".to_string()))?;
    if *revision != expected_revision {
        return Err(E::from(format!(
            "配置保存已陈旧：页面 revision {expected_revision}，当前 revision {}",
            *revision
        )));
    }
    let value = operation()?;
    *revision = revision.saturating_add(1);
    Ok((value, *revision))
}
~~~

fn apply_profit_configuration(
    current: &SpecialOpsSettings,
    update: ProfitConfigurationUpdate,
    validated_moligod_names: &HashSet<String>,
) -> Result<SpecialOpsSettings, String> {
    let mut next = current.clone();
    let deleted_ids = deleted_rule_ids(&next.profit_filter.rules, &update.rules);
    next.profit_filter.enabled = update.enabled;
    next.profit_filter.cutoff_time = update.cutoff_time;
    next.profit_filter.rules = update.rules;
    validate_new_moligod_names(
        &current.profit_filter.rules,
        &next.profit_filter.rules,
        validated_moligod_names,
    )?;
    clear_deleted_profit_references(&mut next, &deleted_ids);
    apply_profit_binding_updates(&mut next, update.bindings)?;
    next.profit_filter
        .audits
        .retain(|audit| next.profit_filter.rules.iter().any(|rule| rule.id == audit.rule_id));
    normalize_profit_settings(&mut next)?;
    validate_profit_configuration_for_save(&next)?;
    Ok(next)
}
