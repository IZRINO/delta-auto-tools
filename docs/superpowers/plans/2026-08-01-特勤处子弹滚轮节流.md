# 特勤处子弹滚轮节流 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 子弹目标滚轮逐次输入并节流，滚动结束稳定 1000ms 后点击；`scrollSteps = 0` 时完全跳过滚动与稳定等待。

**Architecture:** 保持 `AmmoDriver::position_and_click` 契约不变。`input_simulation` 新增仅由子弹定位调用的分段逐次滚轮 helper，现有账号列表滚轮 helper 不改；`special_ops::ProductionAmmoDriver` 将业务步数映射为 `(-1, 50)` 与 `(1, scrollSteps)` 两段并执行。

**Tech Stack:** Rust、Tokio、Enigo、Tauri 2、Vitest、Bun

**执行约束:** Inline Execution；不使用子代理或 worktree；不暂存、不提交；不停止当前开发版。

```rust
fn scroll_region_segments_with_emitter<E: InputEmitter>(
    emitter: &E,
    region: &crate::morse::types::RegionRect,
    segments: &[(i32, u32)],
    step_interval_ms: u64,
    cancelled: &AtomicBool,
    generation: u64,
) -> Result<(), String> {
    let (center_x, center_y) = region_center(region);
    run_cancellable_input_action(cancelled, generation, |_| {
        emitter.move_mouse(center_x, center_y)
    })?;
    let total = segments.iter().try_fold(0_u32, |total, (_, count)| {
        total.checked_add(*count).ok_or_else(|| "滚轮次数超出范围".to_string())
    })?;
    let mut emitted = 0_u32;
    for (delta, count) in segments {
        for _ in 0..*count {
            run_cancellable_input_action(cancelled, generation, |_| {
                emitter.scroll_vertical(*delta)
            })?;
            emitted += 1;
            if emitted < total {
                wait_cancellable_input_delay(cancelled, generation, step_interval_ms)?;
            }
        }
    }
    Ok(())
}
```

增加异步公开 wrapper：

```rust
pub async fn scroll_region_segments_cancellable(
    region: crate::morse::types::RegionRect,
    segments: Vec<(i32, u32)>,
    step_interval_ms: u64,
    cancelled: Arc<AtomicBool>,
) -> Result<(), String> {
    let generation = input_release_generation();
    run_serialized_input(move || {
        let emitter = EnigoInputEmitter::new()?;
        scroll_region_segments_with_emitter(
            &emitter,
            &region,
            &segments,
            step_interval_ms,
            &cancelled,
            generation,
        )
    })
    .await
}
```

fn ammo_scroll_segments(scroll_steps: u32) -> Vec<(i32, u32)> {
    if scroll_steps == 0 {

    } else {
