# 特勤处“继续”即启动调度 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 点击特勤处“继续”后立即 arm scheduler，使逾期任务立即执行、未来任务到点执行，同时保留应用启动强制暂停。

**Architecture:** 复用现有 `RoundScheduler` 原子 armed 状态和单 worker，不增加持久化字段。把误导且执行 `disarm()` 的 `resume_without_launch()` 改为 `resume()`，内部复用 `arm()`；`special_ops_set_paused(false)` 仅在暂停状态持久化成功后调用该方法。

**Tech Stack:** Rust、Tokio paused-time tests、Tauri 2、Bun、Vitest、CodeGraph。

**执行约束:** Inline Execution；不用子代理或 worktree；不 stage、不 commit；保留全部既有未提交改动。

```rust
#[tokio::test(start_paused = true)]
async fn resume_launches_due_round_immediately() {
    let scheduler = Arc::new(RoundScheduler::default());
    let driver = FakeDriver::due_now();
    let worker = tokio::spawn(run_scheduler(Arc::clone(&scheduler), Arc::clone(&driver)));

    scheduler.resume_without_launch();
    settle().await;

    assert_eq!(driver.launches.load(Ordering::SeqCst), 1);
    scheduler.shutdown();
    worker.await.unwrap();
}

#[tokio::test(start_paused = true)]
async fn resume_waits_until_future_task_is_due() {
    let scheduler = Arc::new(RoundScheduler::default());
    let driver = FakeDriver::due_now();
    driver.due_at_ms.store(31_000, Ordering::SeqCst);
    let worker = tokio::spawn(run_scheduler(Arc::clone(&scheduler), Arc::clone(&driver)));

    scheduler.resume_without_launch();
    settle().await;
    assert_eq!(driver.launches.load(Ordering::SeqCst), 0);

    driver.now_ms.store(31_000, Ordering::SeqCst);
    tokio::time::advance(std::time::Duration::from_secs(30)).await;
    settle().await;

    assert_eq!(driver.launches.load(Ordering::SeqCst), 1);
    scheduler.shutdown();
    worker.await.unwrap();
}
```

## 实机验收

1. 应用重启后确认特勤处保持暂停，不自动登录。
2. 配置一个已逾期任务，点击“继续”后确认自动创建 round，无需再点“开始当前到期轮次”。
3. 配置一个未来任务，点击“继续”后确认到点前无输入，到点后自动创建 round。
4. 点击暂停后确认未来任务不执行；再次继续后恢复调度。
5. 休眠超过 60 秒后确认转为暂停，不自动执行逾期任务。
