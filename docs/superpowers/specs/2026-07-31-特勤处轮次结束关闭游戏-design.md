# 特勤处轮次结束关闭游戏设计

## 目标

多账号 round 正常结束，或用户请求的“当前账号完成后暂停”生效时，关闭游戏进程。避免空闲游戏持续占用资源，并确保下一轮从既有登录切号流程重新建立会话。

## 边界

- 仅作用于多账号 round，不影响登录、游戏内导航、单制作台、四制作台批处理或子弹兑换试运行。
- `Completed`：关闭配置中 canonical 完整路径对应的游戏进程。
- `PauseRequested`：当前账号完成并保存状态后关闭游戏，再保持暂停。
- `SystemFailure`、`EmergencyStopped`：不发送关闭操作，保留现场供人工确认。
- 只关闭游戏，不关闭 WeGame。

## 失败处理

- 关闭游戏失败时记录失败步骤与错误。
- 正常完成分支转为全局暂停，禁止下一轮复用残留游戏会话。
- 已暂停分支继续保持暂停，并显示关闭失败原因。
- 关闭动作不改变账号或制作台业务状态，不将账号标记为 `Uncertain`。

## 实现与测试

- 在 round worker 收到最终 `RoundStop` 后、runtime cleanup 前执行关闭动作。
- 复用现有按 canonical 完整路径终止目标进程能力，不新增进程管理抽象。
- 测试覆盖：`Completed` 关闭、`PauseRequested` 关闭、`SystemFailure` 不关闭、`EmergencyStopped` 不关闭、关闭失败转暂停。
