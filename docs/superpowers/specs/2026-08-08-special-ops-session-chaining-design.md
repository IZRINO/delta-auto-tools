# 特勤处跨账号时间序列与同账号会话链设计

## 状态

已获用户确认，已实现并进入验证。

## 目标

修改特勤处轮换执行模型：当前任务完成后，如果全局时间线上下一条任务仍属于当前账号且与当前任务间隔不超过10分钟，则保持游戏会话，停留在四制作台页面等待；否则关闭游戏并切换到下一账号。

该规则只改变实际运行时会话管理，不改变任务的持久化完成时间，也不把时间轴的视觉分组当作执行计划。

## 已确认规则

1. 全局任务按 `scheduledAt` 升序执行；同一时间按账号配置顺序，再按制作台固定顺序和子弹配置顺序。
2. 当前任务完成后，查找全局队列中下一条尚未完成任务。
3. 下一条任务属于当前账号，且与当前任务计划时间差 `<=10` 分钟：
   - 不关闭游戏；
   - 不重新登录；
   - 停留在四制作台页面；
   - 等待任务到期后执行。
4. 下一条任务属于其他账号，或时间差 `>10` 分钟：
   - 结束当前账号会话；
   - 按正常流程关闭游戏；
   - 切换到下一条任务对应账号。
5. 当前账号等待期间出现更早的其他账号任务时，立即结束当前会话，优先处理更早任务。
6. 任务逾期、暂停恢复或调度器唤醒后，重新计算全局队列；不得沿用已失效的等待判断。
7. 账号登录失败、导航第二次超时、仓库隔离、人工状态或其他账号级失败：结束当前会话，跳过该账号，继续全局队列。
8. 系统级失败、紧急停止、休眠时间跳变继续沿用现有全面暂停规则。
9. 时间轴的“10分钟内视觉合并”只用于 UI 展示，不修改 `scheduledAt`，不提前执行任务。

## 示例

### 同账号连续任务

账号1：`10:00`、`10:04`、`10:08`。

`10:00` 登录账号1并完成第一项；下一项仍为账号1且间隔4分钟，留在四制作台页面等待；`10:04` 和 `10:08` 直接继续操作，不重新登录。

### 插入其他账号任务

账号1：`10:00`、`10:04`、`10:08`；账号2：`10:02`。

`10:00` 执行账号1第一项；全局下一项是账号2的 `10:02`，因此关闭账号1游戏并切换账号2。账号2完成后，再按队列返回账号1执行 `10:04`、`10:08`。

### 超过等待窗口

账号1：`10:00`、`10:30`。

两项间隔超过10分钟。`10:00` 完成后关闭游戏；到 `10:30` 再重新登录账号1。

## 运行时设计

### 全局任务队列

在轮次开始时生成冻结的任务快照，至少包含：

- 账号 ID、QQ、账号顺序；
- 任务类型（制作台/子弹）；
- 制作台或子弹目标 ID；
- 原始 `scheduledAt`；
- 当前完成状态和失败状态。

队列排序使用 `(scheduledAt, accountOrder, taskOrder)`。当前账号会话完成一项后，只查看队列中下一条未完成项，不按账号预先整组吞并未来任务。

### 会话链状态

运行时增加当前账号会话上下文：

- 当前账号 ID；
- 当前任务 ID；
- 下一任务 ID；
- 是否保持游戏会话；
- 等待截止时间；
- 当前轮次 generation。

该上下文只属于内存运行态，不写入业务持久化文件。应用关闭、崩溃、紧急停止或休眠跳变后，必须依赖持久化完成时间重新规划，不复用旧游戏会话。

### 等待行为

保持会话时只执行可取消计时，不发送键盘、鼠标或识图操作。等待结束后重新确认当前账号仍是目标账号、游戏窗口仍可用，并从四制作台页面进入下一任务处理。

下一任务提前变为逾期时立即执行，不再等待负时间。

### 账号切换行为

需要切换账号时，先结束当前游戏，再按现有 WeGame 强制重启/账号列表登录流程执行下一账号。账号顺序不因会话链改变，失败账号按现有跳过和人工恢复规则保留在后续轮次。

## 边界与错误处理

- 同账号下一任务恰好间隔10分钟，按“保持会话”处理。
- 下一任务已逾期但仍属于当前账号，直接执行；不重复登录。
- 当前任务执行失败时，不等待同账号后续任务；按现有失败级别结束当前会话。
- 等待期间暂停：停止等待输入，保留原始完成时间；用户继续后重新计算队列。
- 等待期间检测到休眠/时间跳变：全面暂停，不复用当前游戏会话。
- 当前游戏窗口崩溃但 WeGame 未崩溃：按现有游戏恢复规则处理；WeGame 崩溃则重新读取账号状态。
- 关闭游戏失败：按现有 `round.closeGame` 规则暂停，不静默切号。

## 影响范围

- `round_planner`：支持当前任务后的全局后继任务查询，不再只按当前到期账号构造完整会话。
- `round_runner`：增加同账号会话链与等待/切号决策。
- `round_account`：支持同一账号多次任务在同一游戏会话内执行。
- scheduler：活动会话等待期间继续接收暂停、紧急停止、时间跳变和关闭事件。
- 时间轴 UI：保留现有视觉合并逻辑，仅补充会话保持/切号状态展示，不改变任务时间。

## 测试要求

1. 同账号三项任务间隔4分钟、4分钟：只登录一次，三项按时执行。
2. 同账号任务间隔恰好10分钟：保持游戏会话。
3. 同账号任务间隔11分钟：关闭游戏，后续重新登录。
4. 两账号任务插入同账号任务之间：严格按全局时间顺序切换。
5. 当前账号等待时发生暂停：无键鼠输入，继续后重新计算。
6. 等待期间发生休眠时间跳变：全面暂停且不复用游戏会话。
7. 当前账号账号级失败：不执行其后继任务，继续其他账号。
8. 任务持久化完成时间在会话链中逐项保存，崩溃恢复后不重复执行已成功任务。

## 未改变内容

- 制作台四台固定顺序。
- 同账号制作后再执行子弹兑换。
- 每种子弹每日成功一次、失败重试和利润筛选规则。
- 紧急停止、人工校正、账号隔离和 Profile 备份规则。
