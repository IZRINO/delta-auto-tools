# 特勤处制作备注与子弹点击序列设计

## 目标

1. 四制作台“制作物品选择点击点”增加备注，便于用户辨认该点对应的配方。
2. 子弹目标使用“带备注的指定点击点 + A/D 重置后向下滚动位置”。
3. 默认业务配置与账号独立业务配置使用同一模型；当天兑换运行态继续按账号和稳定目标 ID 保存。

子弹兑换执行器尚未实现。本阶段先完成权威数据模型、迁移、校准入口和 UI；后续执行器必须直接消费本规格定义的动作顺序，不得恢复 OCR 目标选择或猜测坐标。

## 制作物品选择点备注

`StationBusinessConfig` 新增 `recipeNote: String`：

- 默认配置四台各自保存备注。
- 账号开启独立设置后，四台各自保存独立备注。
- 开启独立设置时，备注随当时有效默认业务配置复制。
- 关闭独立设置时，独立备注随 `independentBusinessConfig` 永久删除。
- 重新框选 `recipePoints` 坐标时保留备注。
- 删除或清空备注不删除点击点。
- 备注仅用于 UI 展示和人工核对，不参与模板识别、preflight、调度或 runtime 判断。

备注归制作台业务配置，而非 `CalibrationTarget`。这样同一坐标重新校准时无需重写备注，默认账号与独立账号也能保存不同配方说明。

## 子弹目标模型

`AmmoBusinessTarget` 调整为：

```text
id
note
enabled
seasonal
clickPoint
scrollDirection
scrollSteps
order
```

字段语义：

- `id`：稳定目标 ID；当天成功和重试状态继续按该 ID 关联。
- `note`：用户备注，例如子弹名称或位置说明；不参与 OCR。
- `enabled`：是否参与当天兑换。
- `seasonal`：是否先进入赛季限定列表；无赛季目标时不进入该列表。
- `clickPoint`：当前目标在兑换列表中的指定点击点；未配置时允许保存草稿，但自动化 preflight 必须拒绝该目标。
- `scrollDirection`：旧配置兼容字段。保存时保留，runtime 固定按向下解释，UI 不再提供方向选择。
- `scrollSteps`：A/D 重置列表状态后，向下滚动至当前目标的次数；`0` 表示不发送滚轮，但仍等待定位稳定时间后点击。
- `order`：目标执行顺序。

`note` 与 `clickPoint` 都属于业务配置，因此默认配置和账号独立配置均可维护。点击点使用现有 special_ops calibration overlay 单击捕获，不上传参考图，不进入全局 `CalibrationEnvironment.targets`。

## 子弹执行顺序

按 `order` 处理启用目标。每个目标都先用 A/D 重置列表状态，再按自身 `scrollSteps` 向下定位：

1. 普通目标进入普通子弹列表；赛季目标进入赛季限定列表。
2. run 首个键鼠块显示 5→4→3→2→1；后续原本需要提示的块只显示 1。
3. 按 A，等待 100ms；按 D，等待 100ms。
4. 鼠标移动到当前目标 `clickPoint`，逐次向下滚动当前目标 `scrollSteps` 次，每次滚动间隔 100ms。
5. 无论 `scrollSteps` 是否为 `0`，均等待 1000ms，再点击当前目标 `clickPoint`。
7. 执行既定补齐、购买和兑换流程。
8. 处理下一目标时重新执行步骤 2–7。

列表类型发生普通/赛季切换时，先执行既定入口切换，再按当前目标规则重新执行 A/D 与向下定位。当天已成功目标零输入跳过。

仓库空间不足仍是账号级终止条件：判定后不继续该账号其他制作或子弹目标。

## UI

### 四制作台

默认配置和账号独立配置的每个制作台卡片增加：

- `制作物品备注` 输入框。
- 制作物品选择点击点当前坐标。
- `选择` / `重选` 点击点按钮。

继承账号继续隐藏独立编辑器，只显示默认配置摘要。

### 子弹目标

默认与独立子弹编辑器的每一行显示：

- 备注输入。
- 普通/赛季限定开关。
- 启用开关。
- 点击点坐标及 `选择` / `重选`。
- A/D 重置后向下滚动次数。
- 上移、下移、删除。

新增目标生成稳定 ID，默认启用、普通子弹、A/D 重置后向下滚动次数 `0`、点击点为空。删除目标不复用其 ID。

## 校准复用

继续使用：

- `special_ops_begin_calibration_selection`
- `special_ops_submit_calibration_selection`
- `special_ops_cancel_calibration_selection`
- `?mode=special-ops-calibration`
- `special-ops-calibration-*` 窗口 label 体系

command 名、查询参数 mode 和窗口职责不变。校准上下文扩展为显式业务点 scope：

- 全局校准目标。
- 默认子弹目标点击点。
- 账号独立制作配方点击点。
- 账号独立子弹目标点击点。

提交时仍校验 active run、`settingsRevision`、目标存在和 scope 匹配；磁盘写入成功后才替换内存状态。任何失败均不得部分改写坐标或备注。

## 迁移

旧配置按以下规则幂等迁移：

- `StationBusinessConfig` 缺 `recipeNote` → 空字符串。
- `AmmoBusinessTarget.name` → `note`。
- 旧 `scrollSteps` 数值保留，但语义改为“A/D 重置后到当前目标的向下滚动次数”；无需 schema 换算。
- 旧 `scrollDirection` 保留用于兼容读取，保存时归一化为 `down`，runtime 不再读取方向决定输入。
- 缺 `clickPoint` → `null`。
- `id`、`enabled`、`seasonal`、`order` 保留。
- 账号 `AmmoTarget.lastSuccessDay` 与 `retryCount` 原样保留，不复制到业务配置。

迁移后再次加载不得重复生成 ID、覆盖备注、重置点击点或当天运行态。

## 校验与错误处理

- 点击点必须是 `1 × 1` 单点坐标。
- `scrollSteps` 必须为非负整数；`0` 合法。
- 备注允许为空，不作为启动 gate。
- 启用的子弹目标缺点击点：允许暂停状态保存；启动自动化时 preflight 报告目标备注、稳定 ID 和“点击点未配置”。
- scope 指向不存在的账号、目标或未开启独立设置的账号：拒绝提交。
- active run 中禁止新增、删除、排序、框选或修改备注。
- revision 冲突：保留当前 UI 草稿，刷新权威配置并要求用户重新确认，禁止覆盖新状态。

## 测试

### Rust

- 旧制作台配置补空备注。
- 旧子弹名称迁入备注，点击点为空，滚轮方向兼容字段归一化为向下。
- 迁移幂等并保留当天成功和重试状态。
- 默认与账号独立子弹点击点分别写入正确业务配置。
- 账号级制作点重新框选不清空 `recipeNote`。
- 非法 scope、非单点区域、revision 冲突和 active run 均零部分写入。
- runtime 对每个目标按“run 级倒计时 → A → 100ms → D → 100ms → 向下滚绝对步数 → 等待 1000ms → 点击 → 兑换”执行，相邻滚轮事件间隔 100ms。
- `scrollSteps = 0` 不执行滚轮，但仍执行 A/D 与滚动后 1000ms 等待。
- 当天成功目标跳过后，下一目标仍按自身 `scrollSteps` 规则重新执行 A/D 定位。

### 前端

- 默认与独立四台均显示备注输入。
- 默认与独立子弹目标均显示点击点、备注及“A/D 重置后向下滚动次数（0 表示不滚动）”，不显示方向选择。
- overlay 正确透传业务点 scope。
- 新增、删除、排序不复用 ID，且不会修改账号当天运行态。
- active run 时全部编辑与框选入口禁用。

## 非目标

- 本阶段不实现完整子弹兑换 runtime。
- 不使用 OCR 识别已选子弹名称。
- 不自动推断点击点或滚轮次数。
- 不支持任意“点击/滚轮”动作编排；每个目标固定为一次绝对滚轮定位、一次点击和一次兑换流程。
