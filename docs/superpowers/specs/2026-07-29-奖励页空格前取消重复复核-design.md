# 奖励页空格前取消重复复核设计

## 根因

`open_station` 已通过双采样确认 `craft.reward`，但奖励分支随后调用的 `ProductionCraftTrialDriver::press_space` 再次执行 `verify("craft.reward")`。该重复复核发生在按 `Space` 前，造成收取后再次识图。

## 目标流程

```text
open_station 已确认奖励页
  → 3 秒键鼠倒计时
  → 聚焦游戏窗口
  → 按 Space
  → 停放鼠标
  → 直接点击当前制作台
  → 识别当前台制作列表
```

## 实现边界

- 删除 `press_space` 中“正在复核 craft.reward”stage 与 `verify("craft.reward")`。
- 保留取消检查、倒计时、窗口聚焦、Space 输入与鼠标停放。
- 保留第二次制作台点击后的制作列表识别和最多 3 次点击策略。
- 不删除首次点击后用于区分奖励页与制作列表的识别。
- 不修改其他正向守卫。

## 测试

提取最小的奖励关闭动作序列 helper，由测试注入记录型操作，先证明旧序列包含重复复核，再要求新序列只包含倒计时、聚焦、Space 与鼠标停放。现有奖励分支测试继续保证 Space 发生在第二次制作台点击前。
