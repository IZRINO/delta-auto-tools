# 识色2 · 单像素命中 设计

> Issue #63 — 识色调整。在保留现有「识色1（区域平均色判定）」的基础上，新增「识色2（框选范围内出现目标颜色即命中）」。

## 背景与目标

### 现状（识色1）

`src-tauri/src/audio/watcher.rs::match_color_probes()` 对每张识色卡片逐探针执行：

1. 截取探针 `region` 区域
2. `average_region_rgb()` 取整框平均 RGB
3. `color_distance()` 计算与 `target_color` 的欧氏距离
4. `distance <= tolerance` → 该探针命中
5. 按 `ColorMatchMode`（All/Any）跨探针聚合判定是否触发

测试命令 `audio_test_color_match`（`src-tauri/src/audio/mod.rs:468`）复用同一套
`average_region_rgb + color_distance` 判定，存在与 watcher 的重复。

### 需求（识色2）

> 「在探针框选范围内出现目标颜色，在容差范围内则判定成功。不是框选范围内整体平均色，
> 而是在框选范围内的小范围具体色。」

经与用户确认，落地为：

- **匹配方式 = 单像素命中**：框选范围内有任意一个像素与目标色距离 ≤ 容差即命中。不引入新参数。
- **切换层级 = 卡片级**：整张识色卡片统一用 average 或 anyPixel，与现有卡片级
  `colorMatchMode`（All/Any）并列、正交。

### 两个正交维度

| 维度 | 字段 | 含义 | 取值 |
|------|------|------|------|
| 匹配方式 | `colorMatchMethod`（新增） | 单个探针**如何判定**命中 | `average`（识色1）/ `anyPixel`（识色2） |
| 聚合模式 | `colorMatchMode`（既有） | 多个探针**如何聚合** | `all` / `any` |

例：3 探针 + `method=anyPixel` + `mode=all` → 三个探针各自都至少有 1 个匹配像素才触发。

## 方案

采用 **方案 B：抽取统一探针判定助手**。

- 新增 `probe_hit(screenshot, probe, method, count_only) -> ProbeHit`，统一单探针判定。
- `match_color_probes`（watcher）调用它做 per-probe 判定后按 mode 聚合。
- `audio_test_color_match` 复用同一助手，天然拿到命中像素数等调试信息。
- **顺带消除** 现有 watcher/test 的 average 判定重复。

`count_only` 区分两个入口的行为（§2 决策）：

- watcher 路径 `count_only=true`：anyPixel 命中即早退（性能优先）。
- test 路径 `count_only=false`：全扫拿命中数与最近像素（调试优先）。

## §1 — Rust 数据模型（`src-tauri/src/audio/types.rs`）

统一判定助手（消除 watcher/test 重复）：

```rust
/// 单探针判定：按 method 计算 sampled 与目标色的距离，判定是否命中
pub(crate) fn probe_hit(
    screenshot: &image::DynamicImage,
    probe: &ColorProbe,
    method: ColorMatchMethod,
    count_only: bool,
) -> ProbeHit {
    match method {
        ColorMatchMethod::Average => {
            let avg = average_region_rgb(screenshot);
            let dist = color_distance(avg, probe.target_color);
            ProbeHit { matched: dist <= probe.tolerance as f32, sampled_color: avg, distance: dist, matching_pixel_count: 0 }
        }
        ColorMatchMethod::AnyPixel => {
            let scan = scan_region_for_color(screenshot, probe.target_color, probe.tolerance, count_only);
            ProbeHit { matched: scan.matching_count > 0, sampled_color: scan.nearest_color, distance: scan.nearest_distance, matching_pixel_count: scan.matching_count }
        }
    }
}
```

`match_color_probes` 改造——签名加 `method`，调用 `probe_hit`：

```rust
pub(crate) fn match_color_probes(
    screenshots: &[image::DynamicImage],
    probes: &[ColorProbe],
    mode: ColorMatchMode,
    method: ColorMatchMethod,   // 新增
) -> ColorMatchResult {
    let mut hit_count = 0;
    for (i, probe) in probes.iter().enumerate() {
        if probe_hit(&screenshots[i], probe, method.clone(), true).matched {
            hit_count += 1;
        }
    }
    let matched = match mode {
        ColorMatchMode::All => hit_count == probes.len(),
        ColorMatchMode::Any => hit_count > 0,
    };
    ColorMatchResult { matched, hit_count }
}
```

```rust
pub async fn audio_test_color_match(...) -> Result<ColorTestResult, AppError> {
    let (probes, match_mode, match_method) = {
        let inner = state.lock_inner()?;
        let card = inner.settings.cards.iter().find(|c| c.id == card_id)
            .ok_or_else(|| AppError::from("卡片不存在".to_string()))?;
        if card.trigger_mode != types::AudioTriggerMode::ColorWatch {
            return Err(AppError::from("只有识色模式卡片支持识色测试".to_string()));
        }
        if card.color_probes.is_empty() {
            return Err(AppError::from("未配置识色探针".to_string()));
        }
        (card.color_probes.clone(), card.color_match_mode.clone(), card.color_match_method.clone())
    };

    let mut probe_results = Vec::with_capacity(probes.len());
    let mut hit_count = 0;
    for probe in &probes {
        let region = probe.region.as_ref()
            .ok_or_else(|| AppError::from("存在未框选区域的探针，请先框选再测试".to_string()))?;
        let captured = watcher::capture_region(region)
            .ok_or_else(|| AppError::from("截图失败".to_string()))?;
        let hit = watcher::probe_hit(&captured, probe, match_method.clone(), false);
        if hit.matched { hit_count += 1; }
        probe_results.push(ColorProbeTestResult {
            matched: hit.matched,
            sampled_color: hit.sampled_color,
            distance: hit.distance,
            target_color: probe.target_color,
            tolerance: probe.tolerance,
            matching_pixel_count: hit.matching_pixel_count,
        });
    }

    let triggered = match match_mode {
        types::ColorMatchMode::All => hit_count == probes.len(),
        types::ColorMatchMode::Any => hit_count > 0,
    };
    Ok(ColorTestResult { triggered, hit_count, total_count: probes.len(), probes: probe_results })
}
```

## §6 — 测试

遵循项目 TDD 约定（既有 `match_color_probes` 测试在 `watcher.rs` 内 `#[cfg(test)] mod tests`）。

**Rust 新增**（`watcher.rs`）：

1. `scan_region_for_color` 基础：
   - `any_pixel_hit_single_pixel` — 4×4 全黑图中放 1 个目标色像素 → `matching_count >= 1` 且 `nearest_color == 目标色`
   - `any_pixel_no_hit_returns_nearest` — 全图无命中 → `matching_count == 0`，`nearest_color` 为全图最近像素
   - `any_pixel_early_exit_count_only` — `count_only=true` 命中后早退 → 用命中像素恰为 1 的用例断言 `matching_count == 1`
   - `any_pixel_tolerance_boundary` — 像素距离恰等于容差 → 命中（`<=` 边界）
2. `probe_hit`：
   - `probe_hit_average_uses_region_avg` — 非均匀区域 average 模式判定正确
   - `probe_hit_any_pixel_finds_single_pixel` — 同图 average 未中、anyPixel 命中（凸显两种方式差异）
3. `match_color_probes` 新增：
   - `match_color_probes_any_pixel_method_hits` — average 未中但 anyPixel 命中
