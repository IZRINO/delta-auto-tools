# 特勤处联网利润筛选无闪窗查询设计

状态：已获用户确认，待实施计划。

本文补充并覆盖 `2026-08-02-特勤处联网利润筛选-design.md` 中与 Moligod 宿主、查询缓存、round 结束调度和利润筛选 UI 冲突的部分。其余已确认规则继续有效。

## 目标

利润筛选必须在不打断用户正常使用电脑的前提下运行：

1. KKRB 继续是主数据源；仅 KKRB 整体失败时使用 Moligod 备用源。
2. Moligod 利润只能读取网页最终展示的“预估净利润”。工具不得根据材料、手续费或市场价格自行重算。
3. Moligod 查询不得创建或闪现独立顶级窗口，不得抢焦点、占用键鼠、显示倒计时或 toast。
4. “继续”后只允许一次即时利润查询；后续必须遵守既定 5 分钟、5 分钟、50 分钟节奏，round 完成不得重置节奏。
5. 利润规则和业务目标表必须可折叠，运行状态、错误和保存状态仍始终可见。

## 非目标

- 不通过 OCR、截图、模板匹配或网页坐标读取利润。
- 不把 Moligod 页面作为用户可见的攻略页面。
- 不增加任何键鼠占用提示；联网利润查询没有键鼠输入或前台窗口。
- 不把 Moligod 页面公式复制到工具内，也不解析网页脚本来重算利润。

## 数据源裁决

每次利润查询对每条规则只产生一个权威结果：

1. KKRB 正常响应：只使用 KKRB。
2. KKRB 整体失败：只对已填写 Moligod 精确名称的规则启动 Moligod。
3. KKRB 正常但目标缺失、名称重复或该条利润字段无效：保留 KKRB 结论，不以 Moligod 覆盖。
4. Moligod 未配置、页面失败、网络失败、DOM 结构变化或结果校验失败：记为利润来源失败，保持目标待执行。

未达标、目标缺失、未绑定规则和来源失败均不计子弹兑换失败，不隔离账号，不增加游戏内兑换重试次数。利润截止时间后，仍遵守当天成功和重试耗尽排除规则，但绕过利润 gate。

## Moligod 隐藏渲染器

### 宿主边界

现有实现每次查询创建并销毁独立 `WebviewWindow`。即使设置 `visible(false)`，Windows WebView2 仍可能短暂显示该顶级窗口。

新实现改为一个仅供 special_ops 使用的子 WebView：

- 它附着于现有主窗口，不创建独立顶级窗口。
- 它使用专用 webview label、隔离数据目录和最小 capability；远程页面没有 Tauri IPC、文件、shell、窗口、剪贴板或键鼠权限。
- 它在首次导航前隐藏，始终没有可见 UI，不接收焦点。
- 它与“攻略网站”同样使用 WebView 技术，但攻略网站内容对用户可见；本渲染器永远不可见，也不复用攻略网站的 WebView 或 capability。

### 查询流程

1. 仅当 KKRB 整体失败且至少一个规则有 Moligod 精确名称时，懒创建隐藏子 WebView。
2. 每次查询生成新的 `generation` 与随机 `nonce`，并重新导航到 Moligod 兑换页面；禁止复用旧 DOM、旧搜索结果或旧审计利润。
3. 预加载脚本仅接收本次只读目标列表，等待页面自身加载并计算结果，按精确名称读取“预估净利润”。
4. 页面结果经 `generation + nonce`、规则 ID、精确名称、唯一命中和有符号整数格式校验后才可返回 Rust。
5. 成功后保留隐藏子 WebView，供下次查询重新导航复用。
6. 导航、页面、脚本、超时或结果校验失败时，销毁子 WebView；本轮只记录 Moligod 来源失败，下一个调度点允许重新创建。
7. 关闭利润筛选或应用退出时，取消查询、销毁子 WebView、清理隔离数据目录。

### 新鲜度

Moligod 行情快照当前声明 5 分钟浏览器缓存。子 WebView 复用不能因此读取旧行情：

- 每次查询使用新的页面导航标识，确保页面重新挂载。
- 预加载脚本仅对 Moligod 行情快照请求强制网络重载，不改页面配方、排序或利润计算。
- 页面资产可保留缓存；利润依赖的行情快照必须重新请求。

保留现有总查询超时和逐目标 DOM 稳定性检查。整个过程无键鼠输入。

## 调度与 round

利润查询只在每日兑换时间至利润截止时间之间运行，并且同一时刻最多一个查询。

1. 用户在查询窗口内点击“继续”后，启动一次即时查询。
2. 每次查询完成后，无论达标、未达标或来源失败，下一次时间依次为完成后 5 分钟、5 分钟、50 分钟，再从第 1 次重复。
3. 活跃 round 期间不启动新的利润查询，也不向当前 round 注入新目标。
4. 进入活跃 round 时必须保留既有 `nextQueryAtMs`。round 结束后：若已到期则只补启动一次查询；未到期则等待原时间。禁止把它重置为即时查询组。
5. 暂停、关闭利润筛选、应用退出、休眠保护或配置 revision 失效时取消进行中查询并使结果 generation 失效。
6. 暂停后再次点击“继续”按第 1 条建立新的即时查询组；应用启动保持暂停，历史审计不得直接恢复运行期资格。
7. 到达利润截止时间时取消进行中查询或使其结果失效，随后对当天剩余目标绕过利润 gate。

查询结果写盘失败属于系统级持久化故障，沿用现有全面暂停规则；网站查询失败本身不是系统级故障。

## UI

“联网利润筛选”外层始终展开，包含：

- 启用开关、利润截止时间、当前阶段、下次查询时间。
- 最近查询摘要、保存冲突、来源失败和截止时间绕过提示。
- 保存利润配置入口。

以下内容默认收起，折叠状态只属于当前前端界面，不持久化到业务配置：

- `利润规则（N）`：规则编辑、添加删除、KKRB 名称刷新、Moligod 名称验证和每条最近审计结果。
- `业务目标（N）`：业务目标到规则绑定；标题显示已绑定数量。

查询中只显示外层“正在查询利润”状态，不显示 5 秒倒计时、toast 或窗口提示。

## 验收与测试

必须覆盖：

1. 隐藏子 WebView 不创建独立可见窗口，运行期间不改变前台窗口或键鼠状态。
2. Moligod 页面利润由 DOM 读取，不存在本地重算路径。
3. 每次 Moligod 查询重新加载行情快照，连续查询不复用 5 分钟缓存结果。
4. KKRB 正常缺失目标不调用 Moligod；KKRB 整体失败才调用。
5. 结果 nonce、generation、精确名称或唯一性异常时，拒绝结果并仅记来源失败。
6. 继续后即时一次，后续严格 5 分钟、5 分钟、50 分钟；round 完成不重置节奏。
7. 暂停、关闭、截止时间和配置变更能取消过期查询，过期结果不能创建 round。
8. 利润规则和业务目标折叠后，外层运行状态、错误、保存状态仍可见。

实施后运行项目既有完整质量门禁，并增加上述运行时、DOM 结果验证和 UI 折叠测试。
