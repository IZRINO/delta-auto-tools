# 特勤处任务时间轴账号序号设计

## 目标

未来 24 小时任务时间轴在 QQ 账号前显示稳定、易扫读的两位账号序号，例如 `01 账号 481825325`。

## 编号规则

- 序号严格按 `settings.accounts` 当前排列顺序生成，不按任务出现顺序生成。
- 同一账号的制作任务与子弹任务始终共用同一序号。
- 1 至 9 显示为 `01` 至 `09`；10 至 99 正常显示两位数；100 及以上不截断。
- 账号增删或排序后，下一次 render 自动按新顺序刷新。
- 找不到账号时显示 `--`，避免把无效任务伪装成正常账号。

## 实现边界

- 仅修改 React 前端显示逻辑与前端测试。
- 不修改 `TimelineTask`、Rust schema、调度顺序、账号 ID 或持久化文件。
- 在 `SpecialOpsTimeline` 每次 render 时建立一次 `accountId -> 序号` 映射，任务行复用该映射。

## 验证

- 单元测试验证账号顺序映射与两位补零。
- 运行 Special Ops 页面定向 Vitest。
- 运行 `bun run build` 与 `git diff --check`。
