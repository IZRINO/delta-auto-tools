# 特勤处鼠标按住时长设计

## 目标

特勤处自动化的即时鼠标左键点击偶发未被游戏接受。将特勤处的每次鼠标左键点击改为固定按住后抬起，提升点击触发稳定性。

## 范围

- 仅影响特勤处登录、游戏内导航、制作台、子弹兑换和已记住账号选择中的鼠标左键点击；账号复核双击中的两次左键同样适用。
- 固定按住时长为 `100ms`。
- 不新增 UI、持久化字段或用户可配置项。
- 不改变摩斯、连发器、识别触发、计时器、计数器和其他现有 `Direction::Click` 调用。

## 输入行为

特勤处单击与账号复核双击中的每个左键统一执行以下原子序列：

1. 移动鼠标到已校准目标中心。
2. 发送鼠标左键按下。
3. 以现有 `10ms` 取消轮询粒度保持按下，累计 `100ms`。
4. 发送鼠标左键抬起。
5. 按现有流程移动鼠标到特勤处专用停车点。

共享输入层新增显式按住点击 API。特勤处调用该 API；现有即时点击 API 保持语义和实现不变。

## 紧急停止与错误处理

输入状态新增已按下鼠标左键跟踪。紧急停止或输入 generation 失效时，释放路径必须与已按下键盘按键一起最多重试 3 次释放鼠标左键。按住等待检测到取消后，当前点击也必须先尝试抬起左键再返回取消错误，禁止留下按住状态。

任何鼠标按下、等待或抬起失败均沿用调用方既有错误分支；不将失败伪装为成功，不提前更新制作或子弹持久化状态。

## 测试

- 单元测试验证按住点击的事件顺序为移动、左键按下、左键抬起。
- 单元测试验证取消发生在按住期间时仍发送左键抬起，并返回取消错误。
- 单元测试验证紧急释放同时处理已按下键盘按键与鼠标左键，且失败重试次数有上限。
- 单元测试验证账号复核双击中的两次左键均按住后抬起，再发送 Ctrl+C。
- 定向 Rust 测试、`bun run check`、`git diff --check` 和 `codegraph sync` 必须通过。
