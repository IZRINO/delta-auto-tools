# 制作台“制作中”负向守卫设计

## 目标

修正单账号单制作台试运行的初始状态判定。实机确认：制作完成后不稳定显示感叹号，现有 `craft.claimReady.<station>` 不能作为可靠的可收取信号。

新流程只识别稳定的“仍在制作”状态。命中时不点击；标准双采样确认未命中时，当前制作台只可能是空闲或可收取，统一点击制作台，再根据奖励页或制作列表分流。

## 范围

本次修改：

- 单账号单制作台试运行状态机与生产 runtime。
- 制作校准目标、preflight、配置迁移与校准列表 UI。
- 纯状态机及 runtime 回归测试。
- `README.md`、`AGENTS.md`、主设计草案、单账号制作设计和 `droid-wiki/features/special-ops.md`。

本次不实现多账号 round、四制作台批处理、子弹兑换或完整仓库异常恢复。

## 校准模型

在 active `CalibrationEnvironment` 新增一份共享模板配置：

- `craftInProgressReferenceImagePath`：制作台仍在制作时显示的稳定参考图路径。
- `craftInProgressMatchThreshold`：共享 threshold，默认沿用当前模板阈值。

四台分别保存识别区域坐标：

- `craft.inProgress.technicalCenter`
- `craft.inProgress.workbench`
- `craft.inProgress.pharmacy`
- `craft.inProgress.armorBench`

四个 `CalibrationTarget` 只保存独立 rect，不重复保存参考图路径或 threshold。runtime 冻结配置时，把 active environment 的共享参考图和 threshold 与当前制作台 rect 组合成 `RuntimeTemplate`。不能用覆盖四台的大区域替代四个 rect，否则无法判断当前目标台是否仍在制作。

删除默认校准项与执行依赖：

- `craft.claimReady.<station>`
- `craft.idle.<station>`

旧配置缺少共享字段时使用 `null` 路径和默认 threshold。加载旧配置时删除以上八个旧目标，补齐四个 `craft.inProgress.<station>` 区域，并要求用户上传一张共享参考图、分别框选四台区域。旧感叹号或空闲中参考图不得自动迁移成制作中模板。preflight 在共享参考图为空、文件无效或当前台 rect 未配置时拒绝启动。

制作台点击点空间校验改用四个 `craft.inProgress.<station>` 区域作为本台包络。点击点明显落入其他制作台区域且不落入本台区域时继续拒绝保存。

## 初始负向守卫

对当前目标 `craft.inProgress.<station>` 执行一次标准双采样：

1. 两次 similarity 均达到 threshold：判定仍在制作，不点击，正常结束试运行，提示“当前制作尚未完成，本次未执行点击”。不修改账号、制作台状态或完成时间。
2. 两次截图均成功、参考图加载成功，且两次 similarity 均低于 threshold：确认未命中，允许点击制作台。
3. 一次达到 threshold、一次未达到：结果不一致，不点击，返回识别错误。
4. 截图失败、参考图加载失败、取消或采样任务失败：不得降级为“未命中”，不点击并返回实际错误。

负向守卫只允许“两个有效低分样本”触发点击，防止系统错误或抖动被误当成空闲/可收取。

## 点击后结果分流

确认未命中后，点击同一 `craft.station.<station>`，同时观察：

- `craft.reward`
- `craft.recipeListReady.<station>`

分流规则：

### 奖励页

1. 命中 `craft.reward`：判定原状态为可收取。
2. 在 `craft.reward` 守卫下按一次 `Space`。
3. 等待 `game.stationGrid` 双采样命中，确认已返回四制作台页面。
4. 点击同一 `craft.station.<station>`。
5. 等待 `craft.recipeListReady.<station>`，进入现有置顶配方流程。

### 制作列表

命中 `craft.recipeListReady.<station>`：判定原状态为空闲，直接进入现有置顶配方流程，不再执行奖励页或二次制作台点击。

### 无结果重试

每次点击后重新识别奖励页与对应制作列表。两者均未出现时，等待 2 秒，再点击同一制作台。总点击次数最多 3 次。

任一次识别到奖励页或制作列表后立即停止重试。三次点击后仍无结果：

- 记录实际点击次数、两个目标最后两次 similarity 与失败步骤。
- 将账号及当前制作台标记为 `Uncertain`。
- 结束本账号剩余流程；后续自动调度跳过，直到人工确认并修正状态。

## 后续制作流程

进入 `craft.recipeListReady.<station>` 后沿用现有流程：

1. 点击对应 `craft.recipe.<station>` 置顶配方。
2. 识别 `craft.produce` 或 `craft.fill`。
3. 材料不足时执行补齐、购买和生产。
4. 等待 `craft.abort` 标准双采样。
5. 以第二次 `craft.abort` 成功采样时刻记录 `startedAtMs`，按用户配置时长计算 `finishesAtMs`。

本次不修改配方、补齐、购买、生产、中止确认和完成时间持久化语义。

## 停止与失败

- “仍在制作”命中是正常无动作结果，不是失败，不进入 `Uncertain`。
- 负向守卫采样错误发生在首次输入前，不修改业务状态。
- 首次制作台点击后，普通取消、紧急停止或无法归类的识别失败按既有规则标记账号与当前制作台 `Uncertain`。
- 奖励页关闭后 `game.stationGrid` 未命中，或二次点击后制作列表未命中，均属于已发生输入后的不确定状态。
- 所有识别等待继续支持普通取消与紧急停止，并沿用现有 operation window、输入释放、持久化 claim 和资源清理规则。

## UI

点击区域校准列表：

- 增加一项“制作中状态共享参考图”，只上传一次。
- 技术中心、工作台、制药台、防具台各显示一个“制作中状态区域”框选入口。
- 四个区域显示同一共享参考图文件名和 threshold。
- 删除四台“空闲中”与“可收取感叹号”校准项。
- 奖励页、四台制作列表就绪、置顶配方、补齐、购买、生产和中止校准项保持不变。

运行提示：

- 命中制作中：`当前制作尚未完成，本次未执行点击`。
- 初次点击后：`正在识别奖励页面或制作列表`。
- 重试时：显示 `第 N/3 次点击后未识别到结果，2 秒后重试`。
- 三次失败：显示失败步骤、点击次数及两个结果目标的最后采样摘要。

## 测试

Rust 纯状态机与 runtime 测试覆盖：

- 制作中连续双采样命中，零点击并正常结束。
- 两个有效低分样本允许首次点击。
- 一高一低、截图错误、参考图错误或取消不得触发点击。
- 首次点击后进入奖励分支。
- 首次点击后进入制作列表分支。
- 前两次无结果、第三次奖励成功。
- 前两次无结果、第三次制作列表成功。
- 三次无结果后标记 `Uncertain`。
- 奖励关闭后必须等待 `game.stationGrid` 才能二次点击。
- 四台使用各自区域与制作列表目标，但共享同一参考图。
- 旧 `claimReady/idle` 目标迁移删除，新目标补齐且不得错误复用旧参考图。
- preflight 只要求共享制作中参考图、当前台制作中区域及现有后续目标。

前端测试覆盖：

- 校准列表只显示一次共享参考图上传入口。
- 四台分别提供制作中区域框选。
- 不再显示空闲中和感叹号校准项。
- active run 期间共享模板与四个区域均不可修改。
