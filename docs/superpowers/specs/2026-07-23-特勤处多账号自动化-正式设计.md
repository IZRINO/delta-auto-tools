# 特勤处多账号自动化：正式设计

> 状态：登录试运行闭环已实现，完整自动化未通过运行审批。
> 更新时间：2026-07-26
> 来源：[讨论草案](./2026-07-22-特勤处多账号自动化-设计草案.md)

## 目标

在单个 WeGame 与单个游戏进程中，按配置顺序串行处理多个 QQ 账号的特勤处任务：收取到期制作物、重做制作、兑换选定子弹；任务到期后持续进入下一轮。

## 首版范围

- 4 个制作台：技术中心、工作台、制药台、防具台；每台单槽，账号级配置物品与时长。
- 每台可停用；停用台不创建计时。
- 普通子弹与可选赛季限定子弹；账号级目标列表与顺序。
- WeGame QQ 账号密码登录；明文保存、明文导出，导出前二次确认。
- 账号身份只取唯一 QQ 账号；密码允许重复。不读取或比对 WeGame/游戏 ID、UID，不执行身份 OCR、头像/个人主页或剪贴板身份流程。
- 校准向导、逐区域真实识别测试、单账号试运行、暂停、紧急停止、版本化备份。

## 明确排除

- 多开并行、多个 WeGame/游戏进程。
- 游戏内 UID 校验。
- 自动绕过验证码、风控、设备验证。
- 系统托盘常驻。
- 网络时间服务；使用 Windows 系统时间，检测超过 2 分钟跳变后暂停。

## 调度模型

时间字段按 Windows 系统时间保存绝对时间。制作完成时间：

`finishedAt = confirmedProductionStartedAt + configuredDuration`

轮次规则：

- 进入账号时处理该账号全部 `finishedAt <= now` 的制作台。
- 多个任务同时到期时一次进入账号合并处理。
- 每日兑换时间默认 `08:00`，固定 `Asia/Shanghai`，格式 `HH:mm`；当天只成功一次，不补历史次数。
- 制作到期距每日兑换时间不超过 5 分钟时，延迟制作并合并。
- 未处理账号实时并入当前轮次；已处理账号的新任务进入下一轮。
- 无任务账号跳过登录；所有账号无任务时保持等待。

## 账号流程

`结束旧游戏与 WeGame → 打开 WeGame → QQ 密码登录 → 选择置顶游戏 → 启动游戏 → 进入烽火地带 → Tab 大厅视角 → 特勤处 → 账号任务 → 保存状态 → 下一账号`

登录按钮每次 run 只提交一次；提交后只等待置顶游戏入口，不推断密码错误、验证码、风控或网络异常的具体原因。游戏单独崩溃首次重开并从最后成功 checkpoint 继续；WeGame 同时崩溃则为目标 QQ 账号重建完整登录会话；再次崩溃全面暂停。

## 制作流程

`小感叹号 → 点击制作台 → 奖励页面/空格 → 空闲中 → 再次点击同一制作台点击点 → 对应制作台列表就绪 → 置顶物品 → 生产或一键补齐 → 生产 → 中止`

进入制作列表不配置独立点击点，复用技术中心、工作台、制药台、防具台各自的制作台点击点。制作列表就绪模板仍按四台独立保存；区域坐标可相同，但参考图必须包含能区分目标制作台的稳定 UI 特征，禁止使用无法识别台别的通用模板。

收取失败重试 3 次后仍保持小感叹号，判定仓库空间不足并隔离账号。补齐购买价格波动最多重试 3 次；仓库不足立即结束该账号剩余流程。

## 子弹流程

`部门 → 军需处 → 战术部门 → 普通/赛季入口 → 顶部重置 → 滚轮定位 → 一键补齐/兑换 → 二次确认 → 兑换完成状态`

普通组先执行；有目标时才进入赛季限定入口。点击兑换后，先通过用户参考图双采样识别并点击置顶二次确认区域，再通过兑换完成状态参考图双采样确认当天成功；不使用颜色阈值判断。兑换前且实际状态确定的单种失败不阻断其他种类，下一次进入该账号优先重试 1 次。二次确认失败会遗留置顶窗口，因此标记账号 `Uncertain`、关闭游戏并继续下一账号；人工校正前禁止自动重试该账号。

## 安全与恢复

- 普通暂停：完成当前账号后生效；键鼠输入前 3 秒倒计时，等待/加载阶段用户可操作。
- 紧急停止/全局开关关闭：立即停止输入、释放按键，当前账号标记“状态不确定”。
- 休眠、系统时间跳变、应用重启：自动暂停并置顶；用户点击“继续”后执行。
- 仓库不足、状态不确定、窗口异常、登录异常账号进入隔离；人工逐台确认 4 台与当天子弹状态，再点击“解除隔离”。
- 关键状态变化前生成版本备份，保留最近 5 份；数据损坏时禁止自动执行。

## 验收门槛

正式开始前，用户选择一个账号运行试运行模式。试运行只识别，不发送收取、生产、购买、兑换等副作用输入。试运行通过后才允许开始自动化。

校准页每个模板识别区域提供测试按钮，按正式识别规则连续采样两次并报告结果；OCR 区域必须显示真实识别文本与置信度，OCR 引擎未接入时不得伪造测试通过。逐区域测试不能替代单账号完整试运行。

必须实机验证：两个 exe 完整路径进程控制、QQ 登录、置顶游戏条目、启动按钮、游戏 PID/HWND、紧急停止、特勤处导航、4 台制作状态、奖励页面、补齐购买、普通/赛季子弹入口、兑换二次确认、兑换完成状态、崩溃恢复、隔离恢复与备份恢复。
