# 奖励页关闭后直接重开制作台设计

## 目标

制作试运行识别到奖励页并按 `Space` 关闭后，不再等待或识别 `game.stationGrid`，直接点击当前制作台，再按现有流程识别当前制作台的制作列表。

## 状态转换

```text
识别奖励页
  → 按 Space
  → 点击当前制作台对应区域
  → 识别当前台制作列表
  → 选择置顶配方并继续生产流程
```

奖励页关闭后的直接点击不再次执行 `craft.inProgress.<station>` 检查，也不执行 `game.stationGrid` 检查。

## 错误处理

复用 `open_station` 现有策略：最多点击当前制作台 3 次，每次点击后识别当前台制作列表。3 次仍未识别时，记录实际步骤和采样结果，将账号及当前制作台标记为 `Uncertain`。

## 实现边界

- 只删除奖励分支中的 `game.stationGrid` stage 更新与 `wait_ready`。
- 不新增固定延时、配置项、Tauri command 或校准目标。
- 不修改首次制作台点击前的制作中负向守卫。
- 不修改直接进入制作列表的非奖励分支。

## 测试

更新奖励分支单测，断言动作顺序包含一次 `Space`、两次当前制作台点击，且不包含 `wait:game.stationGrid`。保留制作中零点击、空闲直接进入列表及三次重试测试。
