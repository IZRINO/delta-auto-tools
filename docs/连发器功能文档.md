# 连发器功能文档

> 版本：0.5.0 | 更新：2026-05-20

## 概述

连发器是三角洲行动工具的第三个独立工具（与摩斯密码解析、计时器并列）。功能：用户按住触发键时，按固定间隔持续触发目标键，并在松开时自动补齐触发次数为偶数。

## 状态机

```
┌─────────┐  触发键Down  ┌─────────┐
│  空闲   │──────────────▶│ 连发中  │
└─────────┘              └────┬────┘
     ▲                        │
     │                   触发键Up + count 为偶数
     │                        │
     │                   ┌────▼────┐
     │                   │  结束   │
     │                   └─────────┘
     │                        
     │              触发键Up + count 为奇数
     │                        │
     │                   ┌────▼────┐
     │                   │补齐等待 │
     └───────────────────│  1个间隔│
         补齐触发完成     └─────────┘
```

### 状态转换规则

| 当前状态 | 事件 | 新状态 | 说明 |
|---------|------|--------|------|
| Idle | 触发键 Down | Firing | count 重置为 0，启动 tick 任务 |
| Firing | 每个 interval 到期 | Firing | 触发目标键，count+1 |
| Firing | 触发键 Up，count 为偶数 | Idle | 停止 tick 任务，结束 |
| Firing | 触发键 Up，count 为奇数 | PendingCompensation | 停止 tick，启动补齐定时器 |
| PendingCompensation | 等待 1 个间隔后 | Idle | 额外触发 1 次目标键 |
| PendingCompensation | 触发键 Down | Firing | 取消补齐，count 重置，开新一轮 |

### 边界处理

- **极短按 0 次**：直接结束，不触发任何目标键
- **极短按 1 次**：松开时 count=1（奇数），执行补齐，最终 count=2
- **间隔内松开**：立即停止 tick，不等当前周期结束
- **补齐期间再按**：取消补齐，开始新一轮

## 配置结构

### 设置 (`rapidfire_settings.json`)

```json
{
  "version": 1,
  "rapidfireEnabled": true,
  "showOverlay": false,
  "overlayPosition": null,
  "overlayWidth": 400,
  "cards": []
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `version` | number | 设置版本号 |
| `rapidfireEnabled` | boolean | 连发器总开关 |
| `showOverlay` | boolean | 是否显示透明窗口 |
| `overlayPosition` | object / null | 透明窗口位置 {x, y} |
| `overlayWidth` | number | 透明窗口宽度 (320-800) |
| `cards` | array | 连发器卡片列表 |

### 卡片 (RapidfireCard)

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | UUID v4 |
| `name` | string | 卡片名称 |
| `triggerKey` | string | 触发键（单键，如 F1） |
| `targetKey` | string | 目标键（如 1, Space, F3 等） |
| `intervalMs` | number | 连发间隔（最小 10ms） |
| `enabled` | boolean | 是否启用 |

### 目标键支持范围

- 字母键：A-Z
- 数字键：0-9
- 功能键：F1-F12
- 特殊键：Space, Enter, Tab, Esc, Backspace
- 方向键：Up, Down, Left, Right
- 其他：Home, End, PageUp, PageDown, Insert, Delete

## 线程模型

```
Windows Hook (willhook)
  └─ shared-hotkey-listener 线程
       └─ HotkeyMatcher::handle_hold_event()
            └─ HoldAction::Down → RapidfireState::handle_key_down()
            │    └─ 取消补齐任务
            │    └─ 重置 count=0, status=Firing
            │    └─ runtime.spawn(tick_task)  ← tokio runtime
            │         └─ interval.tick() 循环
            │              └─ fire_target_key() + count+1
            │              └─ emit state-changed
            └─ HoldAction::Up → RapidfireState::handle_key_up()
                 └─ abort tick_task
                 └─ count 为奇数？
                      ├─ 是 → status=PendingCompensation
                      │       └─ runtime.spawn(补偿任务)
                      │            └─ sleep(interval_ms)
                      │            └─ fire_target_key() + count+1
                      │            └─ status=Idle
                      └─ 否 → status=Idle
```

## 前端页面

### 主界面

- 左侧：卡片的启用开关和删除按钮
- 右侧：触发键录制、目标键录制、间隔设置（数字输入）
- 每个卡片显示状态徽章：空闲（灰）/ 连发中（绿+脉冲）/ 补齐等待（黄）
- 顶部：总开关 + 透明窗口开关 + 全部停止按钮
- 底部：状态消息栏

### 透明窗口

- 独立 WebView 窗口，label: `rapidfire-display`
- 无边框、置顶、点击穿透
- 每行显示：`[触发键] → [目标键]` | 状态 | 次数
- 可通过 `showOverlay` 开关控制显示/隐藏

### 位置设置窗口

- label: `rapidfire-position`
- 可拖动到目标位置
- Enter 保存，Esc 取消

## 关键约束

- 触发键限制为单键，不支持组合键
- 触发键不能与摩斯密码解析、计时器或其他连发器卡片的按键冲突
- 连发间隔最小 10ms，无最大值
- 新卡片默认禁用
- 卡片删除需确认弹窗
- 兼容旧配置字段 `enabled`（归一化为 `timerEnabled || counterEnabled`）
