# ADR-0001: 连发器功能设计决策

## 状态

已接受

## 上下文

用户需要一个键盘连发功能，用于在游戏中按住触发键时持续触发目标按键，并带有触发次数补齐为偶数的机制。该功能需要作为第三个独立工具加入三角洲行动工具。

## 决策

### 1. 功能定位

**决策：** 连发器作为第三个独立工具，与摩斯密码解析、计时器并列。

**原因：**
- 有独立的状态机（按住→连发→补齐→结束）
- 有独立的配置需求（触发键、目标键、间隔）
- 与计时器的"倒计时→结束"语义不同

### 2. 触发模式

**决策：** 触发键支持单键，也支持包含 Ctrl/Alt/Shift/Win 的组合键（如 `Shift+-`），并按“主键按下启动、主键抬起停止”的方式持续触发。组合键与同主键单键同时配置时，组合键按下会同时启动组合键绑定和单键绑定；松开修饰键只停止组合键绑定，单键绑定持续到主键抬起。

**原因：**
- 部分游戏场景需要避开常用单键，组合触发键可减少误触
- 同主键单键代表玩家仍然按住该物理主键，组合键期间不应被修饰键遮蔽
- 以主键 Down/Up 作为 session 边界，可保持按住连发语义稳定
- 与摩斯、计时器的组合快捷键统一使用同一套热键解析与冲突检测

### 3. 卡片结构

**决策：** 支持多个连发器卡片，每个卡片独立配置。

**原因：**
- 与计时器保持一致的交互模式
- 游戏中可能需要多组不同的连发配置
- 可以通过连发器总开关统一控制

### 4. 配置项

**决策：** 每个连发器卡片包含以下配置项：
- `name` (string): 卡片名称
- `triggerKey` (string): 触发键（单键或组合键）
- `targetKey` (string): 目标键
- `intervalMs` (number): 连发间隔，最小 10ms
- `enabled` (boolean): 卡片是否启用

### 5. 状态机设计

**决策：** 状态机以一次触发键 Down 创建的独立 session 为单位运行：
- Down → 创建 session 和独立 worker 线程
- Firing → Stopping（触发键 Up 或停止信号）
- Stopping → Finished（偶数 count 直接结束，奇数 count 在线程内补齐一次后结束）

**特殊处理：**
- 补齐期间再次按下触发键：不取消旧 session，新建独立 session 并行执行
- 极短按 0 次：本 session 至少触发一次目标键，再按奇偶规则补齐，最终 count=2
- 极短按 1 次：执行补齐，最终 count=2
- 同一触发键绑定多个卡片：同时创建多个独立 session

### 5.1 目标键输入语义

**决策：** 目标键触发必须使用真实按下和抬起序列，不使用系统 click 快捷动作。

**执行序列：**
- `Press(targetKey)`
- 等待 8-12ms 随机抖动
- `Release(targetKey)`

**原因：**
- 浏览器和游戏更容易识别真实按下/抬起状态
- 避免多个连发器共享异步 tick 时互相抢占
- worker 线程在补齐完成后自然退出，减少残留运行态

### 6. 透明窗口

**决策：** 连发器有独立的透明窗口，可开关。

**显示格式：**
```
[触发键] → [目标键]  状态  次数
F1       →  1       连发中 15
```

**状态显示：**
- 空闲：灰色文本
- 连发中：绿色文本
- 补齐收尾期间仍按卡片聚合为连发中

### 7. 持久化

**决策：** 使用独立的 `rapidfire_settings.json` 存储配置。

**配置结构：**
```json
{
  "version": 1,
  "rapidfireEnabled": true,
  "showOverlay": true,
  "overlayPosition": { "x": 100, "y": 200 },
  "overlayWidth": 400,
  "cards": [...]
}
```

### 8. Tauri 命令

**决策：** 新增以下 Tauri 命令：
- `rapidfire_get_bootstrap`: 获取初始状态
- `rapidfire_save_settings`: 保存设置
- `rapidfire_trigger`: 手动触发（测试用）
- `rapidfire_stop`: 手动停止
- `rapidfire_begin_position_selection`: 打开位置设置
- `rapidfire_position_commit`: 保存位置
- `rapidfire_position_cancel`: 取消位置设置
- `rapidfire_position_moved`: 位置设置窗口拖动

### 9. 事件通知

**决策：** 新增以下 Tauri 事件：
- `rapidfire://state-changed`: 状态变化
- `rapidfire://hotkey-error`: 热键错误

### 10. 冲突检测

**决策：** 保存设置时检测热键冲突，范围覆盖所有工具。

**错误提示：** 显示冲突的按键和工具名称。

## 后果

### 正面

- 与现有工具保持一致的交互体验
- 独立的配置和状态管理，便于维护
- 支持多组连发配置，满足不同游戏场景

### 负面

- 需要新增多个 Tauri 命令和事件
- 需要扩展 HotkeyManager 支持按住触发模式
- 需要新的透明窗口和位置设置流程
