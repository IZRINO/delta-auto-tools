# 特勤处自动化使用教程

## 1. 功能范围

特勤处自动化管理多个 WeGame QQ 账号的四制作台循环与每日子弹兑换。

四制作台固定为：技术中心、工作台、制药台、防具台。每个账号的制作计时、制作台状态、子弹当天状态、失败记录均独立保存。

自动化执行顺序：

1. 到点后登录目标账号。
2. 进入游戏并导航到特勤处。
3. 收取所有到期制作台，立即重做同一配方。
4. 满足条件时兑换已配置子弹。
5. 保存本账号最新状态，关闭游戏，继续下一账号或等待下一任务。

工具不保存 QQ 密码，也不输入密码。必须先在 WeGame 中登录每个目标账号并勾选“记住密码”。

## 2. 开始前准备

### 运行环境

- 使用 Windows 桌面版，浏览器预览不能执行原生校准、试运行、WeGame 操作或真实保存。
- 特勤处运行期间需要操作键鼠。执行前关闭会遮挡游戏或 WeGame 的窗口。
- WeGame 和游戏 exe 路径必须在“全局配置”中选择。
- 将目标游戏置顶到 WeGame 游戏列表，避免运行时搜索或滚动游戏列表。
- 每个账号 QQ 必须为唯一纯数字。
- 提前在游戏中预留背包空间、制作材料和兑换货币。

### 推荐配置顺序

按下面顺序完成，避免在未校准时启动轮换：

1. 设置 WeGame 与游戏 exe 路径。
2. 填写默认制作台时长与默认制作物品选择点击点。
3. 添加账号并填写 QQ。
4. 配置子弹目标和需要时的账号独立设置。
5. 完成点击区域、识别区域和参考图校准。
6. 对全部必需模板执行“测试”，直到显示通过。
7. 逐项执行登录、导航、制作、子弹试运行。
8. 对每个账号执行一次人工校正，录入当前四制作台和子弹实际状态。
9. 点击“继续”，让 scheduler 接管到期任务。

## 3. 全局配置

“全局配置”控制所有账号共用项：

| 项目 | 用途 |
|---|---|
| WeGame 可执行文件 | 强制重启 WeGame 时使用的程序路径。 |
| 游戏可执行文件 | 启动、聚焦和轮次结束关闭游戏时使用的程序路径。 |
| 每日兑换时间 | 按 Asia/Shanghai 的 `HH:mm` 解释。到点创建当天子弹兑换任务。 |
| 紧急停止快捷键 | 自定义；只有特勤处操作期间生效。 |
| 导航与制作等待 | 游戏 UI 切换所需固定等待，范围 `0–60000ms`。按实际机器和网络调整。 |

每日兑换时间前 5 分钟内到期的制作任务会延迟到兑换时间，与该账号当天子弹任务合并处理。不会提前执行次日兑换。

## 4. 默认账号配置

默认账号配置是未开启独立设置账号的共同业务模板。

### 制作台

每台可单独启用，设置“小时 + 分钟”时长。保存时转为分钟，范围为 1 分钟至 168 小时。

修改默认时长不会改写已经运行的制作完成时间；下一次该台收取并重做后才使用新时长。

每台还需配置“制作物品选择点击点”。它是进入制作列表后选择该制作物品的位置。四台配方位置可以不同。

### 子弹目标

默认子弹兑换顺序中，每个目标包含：

- 子弹备注：只用于显示和人工识别。
- 启用开关。
- 普通或赛季类型。
- 指定点击点。
- 从列表顶部到该子弹的向下滚动次数。
- 执行顺序。

普通子弹必须排在赛季子弹之前。运行时先完成全部普通目标；存在启用赛季目标时，只点击一次赛季入口，再连续处理赛季目标。

每个目标定位时，工具先按 `A`、等待 100ms、按 `D`、等待 100ms，再按配置次数向下滚动。滚动结束后固定等待，再点击目标。因此滚动次数应从列表顶部重新测量，不应从上一个子弹的位置累计。

## 5. 账号配置与独立设置

在“账号”区域填写 QQ 账号，保持启用。账号按页面顺序轮换。

默认情况下，账号继承默认制作台时长、制作物品选择点击点和子弹目标。开启“独立设置”时，工具会复制当时默认业务配置，随后可单独修改：

- 四台制作物品选择点击点。
- 子弹兑换目标、点击点、顺序和滚动次数。

账号的实际制作计时、当天子弹成功状态和失败状态始终独立保存，不会随继承/独立设置切换而重算。

关闭独立设置会要求二次确认，并永久删除该账号独立业务配置；关闭后重新继承默认配置。

新账号不应直接进入自动轮换。先完成其校准与人工校正，确认当前制作台和当天子弹状态后再点击“继续”。

## 6. 点击区域与参考图校准

“点击区域校准”按当前显示环境全局共享，不按账号复制。显示器、分辨率、DPI、窗口模式或游戏 UI 布局变化后，应重新校准；不要按比例猜测旧坐标。

校准项分三类：

| 类型 | 配置方式 | 用途 |
|---|---|---|
| 点击点 | 框选一个可点击位置 | 进入页面、选择配方、购买、生产、兑换等。 |
| 输入区域 | 框选 OCR 或剪贴板读取范围 | WeGame 已记住账号列表等。 |
| 识别区域 | 框选区域并上传用户参考图 | 确认页面、生产/补齐/中止、兑换确认/成功等。 |

模板识别区域必须同时具备框选范围和参考图片。上传图片后点击“测试”，工具会连续采样两次；两次均通过才允许进入依赖该目标的流程。

参考图片应使用当前游戏版本、当前分辨率和当前 UI 缩放下的真实截图。鼠标悬停、活动弹窗、遮挡窗口、滚动状态不同都可能导致测试失败。

关键校准分组：

- WeGame：登录入口、登录表单、登录、游戏条目、启动入口、账号下拉点、账号列表 OCR、已选账号复制区域。
- 游戏导航：模式就绪、烽火地带点击点、特勤处点击点、四制作台页面。
- 制作：四台点击点、共享置顶配方点、制作中“中止”、四台独立制作物品选择点、生产、一键补齐、购买、返回制作台页面。
- 子弹：部门识别、军需处点击点、战术部门点击点、赛季入口点击点、兑换、一键补齐、购买、二次确认、兑换成功。
- 鼠标停放点：每次输入后工具会先移开鼠标再截图，防止鼠标遮挡识别区域。

## 7. 试运行

试运行会真实操作 WeGame 或游戏。开始前确认游戏界面、账号状态和背包状态可接受。

| 试运行 | 起点 | 成功边界 |
|---|---|---|
| 运行所选账号一次 | 关闭并重启 WeGame | 选中已记住账号、启动游戏。 |
| 游戏内导航试运行 | 当前已打开游戏 | 进入四制作台页面。 |
| 制作试运行 | 当前账号、指定制作台 | 按当前制作状态执行收取/判断/重做分支。 |
| 当前账号四制作台批处理试运行 | 当前账号 | 处理该账号当前到期制作台。 |
| 子弹兑换试运行 | 当前账号 | 依普通、赛季顺序真实兑换所有启用子弹。 |

首个会占用键鼠的操作前显示 5 秒倒计时；后续需要提示的操作只显示 1 秒。固定等待、识别和持久化不会倒计时。

操作提示窗口没有暂停按钮，避免键鼠操作期间误触。普通取消用于试运行；紧急停止用于立即释放工具已按下的键和鼠标。

## 8. 制作流程说明

每个到期制作台按以下逻辑执行：

1. 点击对应制作台。
2. 等待配置时间后按 Space。
3. 再次点击制作台。
4. 点击共享置顶配方点。
5. 双采样识别“中止”。
6. 命中“中止”表示该台仍在制作，点击返回制作台页面，结束该台。
7. 两次有效低分表示进入制作列表，点击该台“制作物品选择点击点”。
8. 识别“生产”或“一键补齐”。
9. 材料足够时点击生产；材料不足时先点击一键补齐、再点击购买。
10. 生产后识别“中止”确认已开始，保存实际开始时间并计算下一次完成时间。

收取成功后游戏会进入奖励页面。工具按固定等待按 Space，再次点击制作台进入后续判断。可收取、制作中、空闲中均不依赖读取倒计时文字。

### 制作购买失败

价格波动或背包空间不足都可能让购买失败。工具以“购买材料按钮”是否仍存在作为反馈，按既有重试规则处理。

连续购买仍无法推进时，当前账号标记为需人工处理，结束该账号剩余流程并继续下一账号。人工处理后应校正实际制作状态；若你已手动收取并重做，按实际剩余时间录入。

## 9. 子弹兑换流程说明

子弹兑换从大厅 UI 进入军需处、战术部门。只有子弹任务时，不必先进入特勤处；制作与子弹同账号时，先完成制作，再从四制作台页面进入兑换。

每种启用子弹每天最多成功兑换一次。单种失败不阻塞其他账号；当天成功立即保存。当天失败达到重试规则后不无限循环，次日按 Asia/Shanghai 自然日重置。

兑换分支：

1. 定位目标子弹。
2. 点击“兑换”或“一键补齐”。
3. 材料不足时点击购买。
4. 点击兑换后双采样识别 `ammo.confirm`，命中后点击确认区域中心。
5. 再双采样 `ammo.success` 确认兑换成功。

兑换确认弹窗或购买反馈不符合预期时，工具停止当前账号本轮并记录该子弹失败；账号其余制作计时不会被覆盖。

## 10. 联网利润筛选

该功能默认关闭。关闭时，子弹是否执行只由启用状态和当天状态决定。

开启后，在“联网利润筛选”中：

1. 点击“刷新 KKRB 名称”，读取可绑定精确名称。
2. 添加利润规则，填写显示名、KKRB 精确名称、最低总利润；Moligod 精确名称可选。
3. 在“业务目标”绑定每个已配置子弹到稳定利润规则 ID。
4. 保存利润配置。

备注不参与利润匹配。一个子弹目标只能绑定一条规则；同一规则可被多个目标引用。

每日兑换时间到利润截止时间之间，工具按“立即 → 5 分钟 → 5 分钟 → 50 分钟”循环查询。KKRB 正常返回时仅用 KKRB；KKRB 整体不可用时才使用 Moligod 备用查询。常规查询结果只在当前应用会话有效，应用重启、暂停或配置变化后需要重新查询。

截止时间到达时，工具冻结当天尚未处理的目标，以固定总利润 10,000 进行最终查询：

- 达标：允许当天兑换。
- 低于 10,000：当天轮空，不记失败。
- 目标缺失、来源失败或利润无效：5 分钟后仅补查一次；仍失败则当天轮空。

利润筛选只影响已配置点击点并绑定规则的子弹。网站存在但工具未配置的子弹会忽略；未满足利润条件不会记为当天兑换失败。

## 11. 暂停、继续与紧急停止

### 暂停

点击“暂停”后：

- 未开始账号：不再启动。
- 正在运行的自动轮次：当前账号结束后停止切换。
- 制作计时继续流逝。
- 到期任务保留，时间轴显示“0 分钟后”。

点击“继续”后，工具先执行 preflight；全部必需校准测试仍有效时才 arm scheduler。逾期任务会立即进入可执行队列。

应用启动、系统休眠/时间跳变恢复、Profile 切换后均保持暂停，必须手动点击“继续”。

### 紧急停止

紧急停止快捷键只在特勤处操作期间有效。触发后立即释放工具输入，不自动重跑当前账号；已发生输入的账号或制作台会标记“状态不确定”。

下次继续前应先进入游戏核实实际状态，再执行人工校正。

## 12. 人工处理与账号状态

账号状态含义：

| 状态 | 含义 | 处理方式 |
|---|---|---|
| 就绪 | 可参与轮换。 | 无需操作。 |
| 需人工登录 | WeGame 账号列表未确认到目标账号。 | 在 WeGame 检查已记住账号后点“已人工检查”。 |
| 登录失败 | 登录或账号选择失败。 | 人工检查 WeGame 后点“已人工检查”。 |
| 需人工检查 | 导航二次超时等账号级问题。 | 确认后点“已人工检查”。 |
| 状态不确定 | 紧急停止、窗口/识别/持久化异常等可能影响业务状态。 | 人工校正制作台与子弹状态。 |
| 已隔离 | 背包空间不足或购买无法推进等业务异常。 | 处理背包/材料后人工校正。 |

### 任务时间轴单项校正

当失败能定位到具体业务时，未来 24 小时任务行会显示直接按钮：

- 制作台：立即到期、正在制作、空闲中。
- 子弹：已兑换、未兑换。

“正在制作”可继承当前剩余时间，也可手工修改。单项保存立即生效，不会等待其他任务。制作台单项校正完成后账号恢复“就绪”；子弹单项校正只恢复该子弹，不阻塞制作调度。

当账号发生登录、账号列表扫描或二次导航超时等账号级问题时，只显示“已人工检查”。该操作不改制作台计时或子弹当天状态。

账号页的“人工校正制作与子弹状态”属于完整覆盖：四台和全部启用子弹必须逐项确认，提交后一次覆盖对应状态并清除失败记录。仅在确实需要整体重建状态时使用。

## 13. 未来 24 小时任务

时间轴展示未来 24 小时内计划执行的制作和子弹任务：

- 同一账号在同一轮应处理的到期任务会合并执行。
- 首任务 10 分钟内的其他任务只做视觉合并，不改变原计划时间。
- 暂停期间到期任务显示“0 分钟后”，恢复后按实际到期状态处理。
- 任务列表是计划投影，不代表某次操作一定成功；失败会显示账号状态或人工处理入口。

## 14. Profile 备份、导入与切换

顶栏 Profile 的新建、复制、导入、导出已包含特勤处配置。

### 备份内容

Profile 保存：

- 账号、顺序、制作台启用状态、时长、当前完成时间和人工失败状态。
- 默认与账号独立业务配置、四台配方选择点、子弹目标及当天状态。
- 全局校准坐标、识别区域、参考图片路径、延时、热键、exe 路径。
- 利润筛选规则、绑定、审计和当天截止决策。

Profile **不保存**：

- 校准参考图片文件本体。
- 正在运行的轮次、操作提示窗口、scheduler 是否已启动。
- 正在执行的利润查询、查询 generation、取消令牌和当次合格目标集合。

因此，导出后应额外备份你上传的参考图片文件，并在新电脑保持相同路径；路径失效时 Profile 仍能导入，但相关校准测试会失效，必须重新上传或替换图片。

### 导入和切换规则

- 导入只把 Profile 加入列表，不会立刻切换，不会关闭游戏或发送键鼠输入。
- 切换 Profile 前如果特勤处存在试运行或自动轮次，工具会拒绝切换。
- 切换成功后特勤处强制保持暂停，并取消利润查询；手动点击“继续”才恢复调度。
- 旧版 Profile 没有 `specialOps` 字段时仍可导入；应用该 Profile 时保持当前特勤处配置不变。

## 15. 常见问题

### 点击“继续”后无法启动

先检查页面提示的具体校准目标。所有必需模板都要有框选区域、参考图，并通过测试。游戏内模板测试会在倒计时后聚焦游戏窗口，测试前不要移动窗口或覆盖识别区域。

### 校准后换了显示器或改了分辨率

不要继续使用旧坐标。重新校准点击点和识别区域，并重新测试模板。图片仅保存路径，不会自动适配 DPI、窗口边框或 UI 缩放。

### 账号被标记为需人工登录

确认 WeGame 已记住目标 QQ、账号列表能显示该账号、没有误点账号后的删除按钮。处理后使用账号卡片的“已人工检查”恢复“就绪”。

### 背包满、购买失败或价格波动

先在游戏内处理背包空间、材料和货币，再按实际状态进行单项或完整人工校正。不要直接重新开始当前账号，否则可能重复生产或覆盖计时。

### 子弹当天没有出现在任务栏

确认目标已启用、当天未成功、已到每日兑换时间；若启用联网利润筛选，还需确认绑定规则、利润合格或截止最终查询达标。当天轮空目标不会作为待执行兑换任务出现。

### 游戏或 WeGame 崩溃

当前不应依赖自动崩溃恢复。保留现场，停止自动化，核实游戏、制作台和账号状态后人工校正，再继续轮换。
